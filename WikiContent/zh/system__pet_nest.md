## 遗种巢

### 概述
- 遗种巢是基地侧的养成与收集系统：**打 Boss 捡崽、基地养崽、崽陪你打架、派崽去送死**。
- 它不是第九个游戏模式，而是给已有的每个模式都多加一层意义：这局要不要带崽？这个 Boss 我还没集到蛋？
- 系统默认**关闭**。在 Mod 设置里打开「遗种巢：养崽与天灾远征」后才会生效。

### 怎么开始

#### 1. 打 Boss，拿遗种
击杀 Boss 时有两条获取轨道，同时生效：

- **遗种蛋（欧轨）**：低概率直接掉落该 Boss 的「遗种蛋」，落在它的战利品箱里。
- **Boss 遗魂（非轨）**：**每次击杀必得**，数量按 Boss 的最大生命值计算。遗魂只用来在巢里定向凝成该血脉的蛋——它不是货币，不进商店。

掉落覆盖标准三档、白手起家、划地为营、血猎追击。宿命回响与末日丧尸模式不掉。

#### 2. 在基地造一座遗种巢
在基地地堡的建造界面里找到「遗种巢」建造。造好后走过去交互，会看到四个选项：

- **查看遗种巢**：崽的名册、出战席位、遗魂账本
- **孵化遗种蛋**：把蛋孵成幼体，或用攒够的遗魂凝一枚蛋
- **派遣天灾远征**：把崽派去三个天灾目的地
- **遗种博物馆**：血脉图鉴与阵亡纪念碑

#### 3. 孵化
孵化时一次锁定三件事，**不可重洗**：

- **出身天赋 ×2**：移速、攻击、生命、背包格子之类的小加成
- **性格 ×1**：莽撞 / 谨慎 / 懒散 / 忠诚
- **异色**：低概率的材质变体，纯收集荣誉，图鉴单独记

蛋的血脉如果因为版本更新而无法识别，系统会提示并**原样保留你的蛋**，不会白白吞掉。

### 带崽进局

#### 出战席位
- 一局最多带 **1 只**崽。在巢里把它设为「出战席位」即可，**不占背包**。
- 进局时系统自动把它生成在你身边；它会跟着你走、自己找敌人打。
- 它的伤害是锦上添花，不改天换地——价值在牵制、补刀，和「它在我身边」。

#### 捡漏背包
带崽出门时，随身仓位会跟着崽走。容量由你自己的宠物容量属性决定，崽的天赋可以再加几格。

#### 你在场，它不死
- 崽被打倒**不会死**，只会**重伤退场**：本局不再出场，回基地自动恢复。
- 每次倒下会留下一道**战痕**：记下时间、地图、是被谁打倒的，外加一条永久的小减益。
- 战痕不是惩罚，是它的履历。每只崽的战痕有上限，更早的会并成「旧伤」计数。

#### 哪些模式不能带崽
| 模式 | 能否带崽 |
| --- | --- |
| 标准三档（弹指可灭 / 有点意思 / 无间炼狱） | 可以 |
| 白手起家 / 划地为营 / 血猎追击 | 可以 |
| 宿命回响 | 不行（宿敌叙事容不下第三者，遥测口径也会被侵蚀） |
| 末日丧尸模式 | 不行（独立生命周期与奖励系统） |
| 百战留痕 | 不行（观战模式，你不下场） |
| 基地 | 崽会在巢边闲逛（最多 3 只） |

### 天灾远征

这是整个系统**唯一会真的死崽**的地方。

#### 三个目的地
| 目的地 | 天灾 | 元素 |
| --- | --- | --- |
| 风暴海域 | 雷暴 | 电 |
| 酸雨废墟 | 毒雨 | 毒 |
| 极寒荒原 | 暴雪 | 冰 |

崽的血脉元素与目的地匹配时，成功率会上浮——收集不同血脉从此有功能意义。

#### 三个风险档位
| 档位 | 收益 | 死亡率 |
| --- | --- | --- |
| 平安 | 低 | 0，绝对安全，最多空手 |
| 风浪 | 中 | 低，可能负伤留疤 |
| 亡命 | 高 | **真实存在**，押命换稀有产出 |

**死亡率在出发前就写在按钮上**，而且会随这次出发固化——之后就算数值调整，也不影响已经派出去的这一趟。

#### 倒计时与结算
- 倒计时走**现实时间**：关掉游戏也照样走。
- 回到基地时自动结算，然后逐张翻牌：战利品 / 负伤 / 空手 / 死讯。
- 翻牌只是回放——结果在你回基地的那一刻就已经定下并存好了。中途退出游戏，下次回基地这张牌还在。
- 崽真的死了就**不可逆**：它从巢里消失，名字刻上纪念碑。

### 遗种博物馆

- **血脉图鉴**：每个血脉一页，首次孵化解锁。记击杀数、孵化数、异色获得、最高等级、远征次数。
- **阵亡纪念碑**：远征死亡的崽永久刻名——名字、血脉、殁于何处、**当时你选的那个风险档位**、出发时的死亡率、生前战绩。
  「亡命」两个字是你自己按下的，碑文替系统记住这一点。
- **驯养成就**：初为人父、血脉收藏家、全谱系执念、淡紫色的那只（异色）、碑上有名。

### 小贴士
- 遗魂只用于凝蛋。攒够同一血脉的遗魂，就能定向拿到那个 Boss 的蛋——非酬玩家也能集齐图鉴。
- 巢容量有限，孵化前先看看还有没有位置。
- 想安全赚一点就走平安档；想赌一把就看清死亡率再按亡命。
- 派出去的崽在远征期间不能带进局，也不能移除——调度张力就在「这几天没它陪我」。
