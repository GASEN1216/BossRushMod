## 岛主装备

[tip] 只从天空岛的两位岛主「悬根猎首」与「穗镰」身上来：它们每趟都穿着全套出现，倒下时按权重只留下**其中一件**，占尸体箱一格；箱里其余是它原本带着的东西。

### 这是啥？

**悬根林的岛主「悬根猎首」与青穗梯田的岛主「穗镰」身上穿的两套装备**：根须面罩、藤编甲、悬根箭囊是悬根猎装，出自猎首；青穗斗笠、蓑衣甲、谷囊是蓑衣农装，出自穗镰。穿上就有官方头甲 / 体甲 / 背包容量；在群岛上两套还各有用处 —— 悬根猎装任意两件让搜刮箱里多出岛上特产的机会翻倍，蓑衣农装任意两件让割青穗草一次多割一份。残星匠首那一套见「星工装备」，头目身上的单件见「头目装备」。

### 六件装备

- **根须面罩**（面罩）：品质 5，头甲 +1，耐久 40，物品 ID 500090
- **藤编甲**（护甲）：品质 5，体甲 +3，耐久 100，物品 ID 500091
- **悬根箭囊**（背包）：品质 5，背包容量 +6，物品 ID 500092
- **青穗斗笠**（头盔）：品质 5，头甲 +2，耐久 60，物品 ID 500094
- **蓑衣甲**（护甲）：品质 5，体甲 +3，耐久 90，物品 ID 500095
- **谷囊**（背包）：品质 5，背包容量 +7，物品 ID 500096
- **维修**：有耐久的四件可在维修台修复（两只背包没有耐久）
- **死亡掉落**：没有绑定标签，出击中倒下会和身上其他装备一起留在原地

### 获取途径

- **悬根猎首**（岛主，悬根林风标守卫的带队者）：每趟出击都在。倒下**必掉一件**：根须面罩 35%、藤编甲 35%、悬根箭囊 30% —— 多打几趟才凑得齐。
- **穗镰**（岛主，青穗梯田水车渠与谷仓之间那一组的带队者）：每趟出击都在。倒下**必掉一件**：青穗斗笠 35%、蓑衣甲 35%、谷囊 30%。
- 掉出来的那件**耐久是满的**；它身上没抽中的几件不会进箱子。
- 不进任何随机奖池（岛上物资池、许愿台、日报签到、Boss 随机箱都抽不到），只有这两位身上这一条路。

### 在群岛上的用处

**悬根猎装两件套**（根须面罩 / 藤编甲 / 悬根箭囊任意两件同时穿着）：
- 岛上的搜刮箱每箱本来就有一次机会**额外**多装一件岛上特产（归航菜便当、星苔药膏、风标罗盘），穿着两件时这个机会**翻倍**；箱子原本的件数与品质不变。
- 箱子是你走近时才装填的，看的是那一刻身上穿着几件。

**蓑衣农装两件套**（青穗斗笠 / 蓑衣甲 / 谷囊任意两件同时穿着）：
- 在青穗草丛采集时**多得 1 份青穗草**；每处每趟照旧只能采一次。

### 打法提示

**悬根猎首：**
- **根索**：你进到它 **20 米**内时，它在你们之间立起**两根根桩**，桩间拉一道约 8 米长的绊索。绊索先松着，约 0.8 秒后才绷紧，12 秒后自己消失；绷紧后跨过或贴近就会被绊住 —— 挨一下、走跑**慢 45%，持续 2.5 秒**，绊索随即断掉。
- **先打掉任意一根根桩**（30 点血），绊索就断。
- **根洞伏击**：血量降到 **75% / 45%** 时，离你最近的一处根洞亮起一圈（半径 2.5 米），约 1 秒后它从那里钻出来炸一圈 —— 看见根洞亮就离开那处。钻出来后它会**愣 1.5 秒**，这是输出窗口。
- **打坏装备会断招**：根须面罩被暴击打穿后，根洞要亮 2 秒它才钻出来；藤编甲耐久打光后，绊索的减速只剩一半。

**穗镰：**
- **开闸放水**：血量降到 **80% / 50% / 25%** 时，在你脚下和左右两侧（各离 5.5 米）各冲出一块烂泥（半径 3.5 米）。泥约 1.2 秒后才漫开，漫开前踩进去不减速；漫开之后留 12 秒，站在泥里走跑都**慢 40%**。
- 第一次开闸时它会朝谷仓吆喝，把**谷仓那一组还活着的帮手**喊过来 —— 先清掉谷仓那边就没人来。
- **镰扫**：你贴到它 3 米内时，它脚下亮圈，约 0.9 秒后扫一圈（半径 2.2 米），冷却 4 秒 —— 保持距离，看到圈就退。
- **打坏装备会断招**：青穗斗笠被爆头打穿后，开闸只冲出一块泥；蓑衣甲耐久打光后，镰扫的预警慢到 1.6 秒。

[tip] 两位都有 Boss 血条和名字，打倒过也每趟都会回来；首杀会记进群岛手记的总览。戴着静听耳罩时，它们的预警圈都亮得更久（见「头目装备」）。
