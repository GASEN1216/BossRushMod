## 龙王套装

### 这是啥？

龙裔套装的**升级版**，焚天龙皇掉落。火焰转治疗照旧，冲刺远得多，还去掉了龙裔套装的毒素易伤和视野缩小。**拿到就不用再换了。**

### 套装部件

#### 龙王之冕（头盔）
- 护甲：7 / 耐久：200 / 物理承伤倍率：-15% / 枪械暴击伤害：+15%
- 风暴抗性：+1 / 寒冷抗性：+1 / 火焰承伤倍率：-20% / 电击承伤倍率：-20%
- 掉落：焚天龙皇（**15% 掉率**）
- 相比赤龙首：暴击更高，没有毒素易伤，没有视野缩小

#### 龙王鳞铠（护甲）
- 护甲：7 / 耐久：200 / 物理承伤倍率：-25%
- 风暴抗性：+1 / 寒冷抗性：+1 / 火焰承伤倍率：-25% / 电击承伤倍率：-25%
- 掉落：焚天龙皇（**15% 掉率**）
- 相比焰鳞甲：没有毒素易伤

### 两件齐穿——龙王模式启动

- **火焰转治疗** — 火焰伤害不扣血，反而回复火焰部分实际伤害的 80% 生命值
- **龙眼光效** — 头部出现红色呼吸灯（纯外观）
- **龙王冲刺** — 6 米冲刺，冷却仅 0.5 秒
- **二段冲刺** — 首段冲刺后 0.15 秒内按方向键可追加 3 米
- **熔浆轨迹** — 冲刺路径留下熔浆灼烧（每 0.5 秒 5 点伤害，持续 3 秒），**一边跑一边烧敌人**
- **金橙残影** — 冲刺时留下金橙色残影（龙裔套装是橙红色）

### 比龙裔套装强多少？

- **冲刺距离** — 龙裔：3 米；龙王：6 米 + 3 米二段
- **冲刺冷却** — 龙裔：1.5 秒；龙王：0.5 秒
- **熔浆轨迹** — 龙裔：无；龙王：有
- **毒素易伤** — 龙裔：有；龙王：无
- **视野缩小** — 龙裔：有；龙王：无
- **枪械暴击伤害** — 龙裔：+10%；龙王：+15%

[tip] 每一项都比龙裔套装强，拿到龙王套装后，龙裔套装就可以收起来了。
