## 头目装备

[tip] 只从天空岛的七位头目身上来：截信人、听雨人、蚋笛翁、镜中客各穿一件，倒下 30% 留下；三位断风游猎各穿断风套里的一件，倒下 40% 留下。掉出来的那件占尸体箱一格，箱里其余是它原本带着的东西。

### 这是啥？

**七位头目各自穿着的一件装备**：旧邮包出自倒挂邮亭的截信人，静听耳罩出自听雨洞的听雨人，苔纱面罩出自蛙鸣池的蚋笛翁，镜纹甲出自镜水寺的镜中客；断风披甲、断风行囊、断风兜帽合称断风套，分别出自守着三座回程中继平台的断风游猎 · 追、伏、守。穿上就有官方的背包容量、听觉、头甲或体甲；在群岛上每件还各有用处 —— 信鸽多送一封信、头目预警更久、云蚋不躲枪口、和折翎和解不必带旧信与航路图，断风套凑两件走桥更快。瞭台观星手的观星镜盔见「星工装备」。

### 七件装备

- **旧邮包**（背包）：品质 4，背包容量 +4，物品 ID 500093
- **静听耳罩**（耳机）：品质 4，听觉 +0.5，耐久 40，物品 ID 500097
- **苔纱面罩**（面罩）：品质 4，头甲 +1，耐久 40，物品 ID 500098
- **镜纹甲**（护甲）：品质 5，体甲 +2，耐久 80，物品 ID 500099
- **断风兜帽**（头盔）：品质 4，头甲 +2，耐久 50，物品 ID 500100
- **断风披甲**（护甲）：品质 4，体甲 +2，耐久 70，物品 ID 500101
- **断风行囊**（背包）：品质 4，背包容量 +5，物品 ID 500102
- **维修**：有耐久的五件可在维修台修复（旧邮包与断风行囊没有耐久）
- **死亡掉落**：没有绑定标签，出击中倒下会和身上其他装备一起留在原地

### 获取途径

- **截信人**（头目，倒挂邮亭）：倒下 **30%** 掉旧邮包，70% 不掉。
- **听雨人**（头目，听雨洞）：倒下 **30%** 掉静听耳罩，70% 不掉。
- **蚋笛翁**（头目，蛙鸣池，**只在夜里出来**）：倒下 **30%** 掉苔纱面罩，70% 不掉。
- **镜中客**（头目，镜水寺，**只在夜里出来**）：倒下 **30%** 掉镜纹甲，70% 不掉。
- **断风游猎 · 追 / 伏 / 守**（头目，悬根林 K1、残星工坊 K2、鸣风栈道 K3 三座回程中继平台）：追穿断风披甲、伏背断风行囊、守戴断风兜帽，倒下各 **40%** 留下自己那件，60% 不掉。凑齐断风套要三位都打。
- 「夜里」是游戏时间 21 点到次日 5 点：白天去蛙鸣池和镜水寺只见随从，头目要到夜里你走近时才出来。
- 掉出来的那件**耐久是满的**。
- 不进任何随机奖池（岛上物资池、许愿台、日报签到、Boss 随机箱都抽不到），只有这几位身上这一条路。

### 在群岛上的用处

**旧邮包**（背在背包槽）：
- 背着它在岛上，只要还有没收到的信，**信鸽这一趟多送一封**（每趟一次）。

**静听耳罩**（戴在耳机槽）：
- 所有头目与岛主的预警（地上的圈、冲锋线、绊索绷紧、吹笛那一下）都**亮得更久**，按 1.25 倍算。
- 听雨人要你在洞口开 **16 枪**才落一次石（不戴是 8 枪）。

**苔纱面罩**（戴在面罩槽）：
- 身边的云蚋认不出你在瞄它，**不再躲你的枪口**。

**镜纹甲**（穿在护甲槽）：
- 穿着去见折翎，他认得这身纹路：**不带旧信与航路图也能和解**。只看你见他时穿没穿着。

**断风套两件套**（断风兜帽 / 断风披甲 / 断风行囊任意两件同时穿着）：
- 站在**桥和中继平台**上时走跑**快 12%**，一下桥就恢复。

### 打法提示

**截信人：**
- 你贴到它 **2.5 米**内、背包里有岛上耗材时，它脚下亮圈伸手 **0.8 秒**；圈亮完你还在 2.9 米内，就被抢走一件**最值钱的岛上耗材**（便当、药膏、风灯、驱风香、护符、纱笠、灭蚊灯、蒲扇里挑，整堆只拿一个；纪念品、材料与官方物品不碰）。随后它闪到邮亭离你远的那一头，**跑速 +30%，持续 6 秒**。
- 伸手亮圈时后撤就会抓空。一场最多抢两次。
- 被抢了就追上去打：东西在它身上，倒下时照样进它的尸体箱。
- 血量打到**四成以下**，它把抢来的东西丢在脚下，此后不再劫包。

**听雨人：**
- 它数你在**洞口一带（洞岩 26 米内）**开的枪（按扣扳机算，霰弹一枪也只算一次），每满 **8 枪**就让洞顶在你身边落 **2 块石头**（半径 2.4 米，约 1.4 秒预警）。
- 在洞口少开枪、换近战，或者把它引出洞口再打，计数就不涨。
- 它戴的静听耳罩被暴击打穿后，就再也听不见枪声、引不下石头。

**蚋笛翁：**
- 你走近（30 米内）时它站定**吹笛 1 秒**，脚下亮圈（这个圈不伤人）；吹完把云蚋招到你身边，**8 秒内全场云蚋都往你身上扑**，灭蚊灯也引不走。约每 9 秒一次。
- 吹笛那一秒里打掉它 **8 点血**，笛声就断。
- 它的苔纱面罩被暴击打穿后，就再也吹不响笛子。

**镜中客：**
- 你在**镜池一带（45 米内）**时，它每隔约 8 秒在你**背后**、与它关于你对称的位置亮一圈（半径 1.8 米），**1.1 秒**后翻过去落地震一下，原地留下一个半透明的**倒影**（20 点血，6 秒后自散）。
- 看见身后亮圈就转身挪出圈。**先打碎倒影**，它会失衡 **3 秒**，这期间不翻身。
- 你走到离镜池 45 米外，它就不再翻身。
- 它的镜纹甲耐久打光后照样翻身，但再也留不下倒影。

**断风游猎（三位共通）：**
- 你在它 **6–28 米**内时，地上画一条从它脚下到你面前的**冲锋线**、落点亮一圈（半径 1.8 米）；线亮满就冲过来落地震一下，然后**硬直 1.2 秒**。冲锋线亮起就**横着让开**。
- 它们整组和岛上的拾荒者**不是一伙**，见面就打 —— 可以引过去让它们先打起来。
- **追（K1）**：连冲两步，第一步停在你面前，第二步重新瞄你此刻的位置、停到你**身后**再震一下 —— 两步都要让。冲锋线约亮 0.9 秒，断风披甲耐久打光后亮两倍久。
- **伏（K2）**：冲一步就闪回起手点，躲在平台边缘补枪 —— 别追过去对枪，等它下一次冲过来。血量打到一半，它的行囊散开，不再闪回。
- **守（K3）**：只冲一步，冲锋线亮得最久（约 1.2 秒），三位里最好读 —— 先打它练熟冲步。断风兜帽被爆头打穿后亮两倍久。

[tip] 几位都有 Boss 血条和名字，打倒过也每趟都会回来；首杀会记进群岛手记的总览。找浮舟、苇白、晴禾、眠苔说话时，他们会提起还没打倒的那几位在哪、怎么躲。
