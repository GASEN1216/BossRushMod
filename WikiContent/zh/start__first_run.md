## 新手上路

### 第一步：搞张船票

去基地商人那里，买一张 **BossRush 船票**——这是你踏入 Boss 竞技场的入场券，没它哪儿也去不了。

顺手再拿三样东西：

- **成就勋章** — 免费的，白拿不拿是傻子。右键打开成就面板
- **冒险家日志** — 就是你现在在看的这本百科书，随时翻
- **鸭皇图鉴** — 4000 块，全店只有一本。它自动记录你亲手打死的每个 Boss，
  光「解锁第一个条目」的成就就返你 5 万。**这是全 Mod 回本最快的一次消费**

### 第二步：挑张地图

有了船票，地图选择界面会解锁 9 张 BossRush 地图。第一次？直接选 **DEMO 终极挑战**，
场地又大又平，Boss 从哪个方向来一眼看得见。

### 第三步：选个难度

落地之后，你会看到场地中央有块路牌。走过去互动，选难度：

- **弹指可灭** — 每波 1 个 Boss，适合试水，一个一个慢慢揍
- **有点意思** — 每波 3 个 Boss 一起上，节奏感拉满
- **无间炼狱** — 无限波次，Boss 越打越强，看你能撑几轮

### 第四步：开打！

- 标准难度下每波 Boss 死了会掉箱子，里面全是好东西；无间炼狱不掉箱，改发现金和里程碑大奖
- 波次之间有休息时间，够你翻翻箱子、补补弹药
- 路牌旁边有弹药商店、维修站和垃圾桶——文明竞技，别乱扔箱子
- 打着打着可能会有**随机事件**：空投砸下来、月亮变红、天上下钱，或者一只不该出现的
  Boss 闯进来。都有横幅播报和倒计时，到点自动收场，详见「局内随机事件」

### 回基地之后，先做这三件事

第一局打完撤离，回到基地，有三件很便宜但会一直产出的事：

- **造一个报箱**（500 金）— 每个游戏日出一份《鸭科夫日报》，里面有每日悬赏和签到墙，
  签满就发高品质奖品。造好就不用管了，它自己会攒
- **造一块征程公告板**（500 金）— 接「鸭王征程」的第一章契约。六章剧情把你已经在玩的模式
  串成一条调查线，第一章只要求你通关一局标准竞技场并且前 2 波不掉血，交付给你 2 万
  外加解锁基地菜地
- **去找叮当和羽织** — 每天聊天送礼刷好感度。叮当 Lv.2 开商店、Lv.4 送冷淬液，
  之后就能重铸装备了

[tip] 报箱和公告板加起来 1000 金，是这个 Mod 里最划算的两笔基建。越早造，越早开始攒。

### 打完之后呢？

标准 BossRush 觉得不够刺激了？试试这些：

- **白手起家** — 裸装 + 船票，系统随机给你发装备，拿到什么用什么
- **划地为营** — 裸装 + 营旗，选个阵营，满图 Boss 大乱斗
- **血猎追击** — 裸装 + 船票 + 血猎收发器，进去就开始掉血，不杀 Boss 就等死
- **宿命回响** — 当前装备 + 船票 + 宿命回响信物，九波三幕，Boss 会反制你的打法
- **百战留痕** — 只要一张船票。你不下场，签两名斗士替你打六场，你负责看盘、下注、喊口令
- **无间炼狱** — 选无间炼狱难度，看看自己的极限在哪

### 新手锦囊

[tip] 路牌上有个"返回出生点"，迷路了或者被打残了赶紧用。

[tip] 按 L 键随时看成就进度——有些成就的奖金够你吃几顿好的。

[tip] 别忘了回普通地图找叮当和羽织，和他们搞好关系能解锁一大堆实用服务。叮当那边除了重铸还有**词缀锻造**，能给装备打上「击杀时爆炸」「命中吸血」这种改变打法的词缀。

[tip] 竞技场里的 Boss 死了都会给你一笔**遗魂**（血越厚给越多），还有约 4% 直接掉一枚**遗种蛋**。就算你还没造遗种巢，这些也已经在替你攒着了——等哪天造好巢，直接就能孵。蛋掉在 Boss 身上，记得搜尸。
