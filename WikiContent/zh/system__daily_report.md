## 鸭科夫日报

### 这是什么

《鸭科夫日报》是一份会自动送到你基地的报纸，每个游戏日出一期，把你昨天干的事写成新闻。

它不给你任何战斗上的加成，它给的是**节奏**：一份每天固定要做的小事，一条今天该往哪打的
悬赏，和一面签满就发奖的签到墙。打完一轮回基地，顺手翻一份报纸——这个 Mod 的基地生活
就是这么一点一点铺开的。

至于报纸怎么写你，那就不一定是好话了。

### 如何开始订阅

- 在基地的建造界面里造一个 `报箱`，造价 `500` 金，**只能建一个**，位置随你摆。
- 造好后靠近它，会看到交互选项 `阅读今日报纸`。
- 打开后就是完整的报纸面板。

### 一天有多长

- 一个游戏日约等于 `24` 分钟现实时间（游戏内时钟是现实时间的 60 倍速）。
- **只要游戏在跑就算**：你在基地挂机也照样推进，暂停和停留在主菜单时不计时。
- 睡觉和"继续游戏"造成的时间跳跃**不会**让你白跳一期——日报按实际游玩时长自己算天数。
- 退出游戏不会算作断签：计时器只在你实际游玩时前进。
- 报纸顶部会显示当日进度百分比，你随时能看到离下一期还有多远。

### 报纸上有什么

- **头版头条**：根据你昨天的表现自动选题。砍了首领、屠了几十个杂兵、连着阵亡好几次、
  或者大赚一笔，都会有对应的稿子。什么都没发生也有专门的稿子。
- **昨日战绩**：击杀数、首领数、出击与撤离次数、阵亡次数、收支、最大单次伤害。
  百战留痕的比赛不进这一栏——那是你的选手在打，不是你的战绩，悬赏进度同理不推进。
- **悬赏栏**：公布昨天的悬赏结果，同时给出今天的新悬赏和实时进度。
- **气象与杂谈**：明日天气预报（含风暴预警）、今日运势的宜与忌、坊间传闻。
- **签到墙**：一整期 30 格。

### 每日悬赏

每天一条，从五类里随机抽一条，还会随机抽一个难度档（轻松 / 常规 / 硬核），
目标和奖金一起变：

- **清剿敌人** — `30 / 60 / 120` 名，奖金 `800 / 1,600 / 3,200`
- **讨伐首领** — `1 / 3 / 5` 只，奖金 `1,200 / 3,000 / 5,000`
- **成功撤离** — `1 / 2 / 4` 次，奖金 `700 / 1,400 / 2,800`
- **单日进账** — `5,000 / 15,000 / 40,000`，奖金 `900 / 2,000 / 4,500`
- **零阵亡出击** — 固定奖金 `1,500`

几条规则：

- 同一天无论重开几次游戏，悬赏都是同一条，**不会刷新**。想换只能等明天。
- 报纸上写着实时进度，随时能回来看还差多少。
- 达成后会在**次日的报纸上公布**，奖金自动发放。
- 「零阵亡」需要你当天**至少出击过一次**，整天待在基地不算数——不出门当然不会死。

[tip] 早上先翻一眼报纸，把今天的悬赏和你本来就想打的模式对上：抽到「讨伐首领 5 只」就去打标准竞技场，抽到「成功撤离 4 次」就打短局。顺路赚的钱才是白赚的。

### 签到与奖励

每天打开报纸点一次 `签到`，一天只能签一次。一期 30 格。

**第 1 期**是入门期，奖励逐级往上走：

- 第 `7` 格 → 品质 `5` 随机奖品
- 第 `15` 格 → 品质 `6`
- 第 `24` 格 → 品质 `7`
- 第 `30` 格 → 品质 `8`

**第 2 期开始**换成稳定发放：格子编号从 31 数到 60，每一期的第 `7 / 14 / 21 / 28` 格
各发一件，**品质固定为 `8`**。也就是说熬过第一个月之后，每周都有一件顶级奖品。

- 里程碑格在签到墙上是金色的，带 `★` 标记，隔多远都看得见。
- **断签会清空本期进度**：某一天没签，跨天时本期格子清回 0 重新开始。
  但**已经翻过的期数不会退回去**——你不会从第 2 期掉回第 1 期，也就是说奖品品质不会倒退。

[warn] 断签的代价是「这一个月白攒了」，不是「一切归零」。真断了也别弃疗，第 2 期起每 7 格就有一件 Q8，重新攒一周就能回本。

### 奖品去哪了

- 奖品默认寄到**快递站的待领取列表**里，不会直接塞进你的背包。
  屏幕上会弹一条「签到奖励已寄往快递站」的提示。
- 因此你在打副本的途中跨天也没关系，东西丢不了，回基地慢慢取。
- **万一快递站收不下**（比如缓冲满了），系统会退而求其次直接把奖品塞给你——
  进背包、进仓库，或者掉在你脚下。这种情况下它**不会**再往快递站补一份，
  所以别看到快递站没东西就以为丢了，先翻翻背包和脚底。
- 真的两条路都失败了才算发放失败，下次打开报纸时会自动补发。

### 需要开启吗

- 不需要。日报随 Mod 默认启用，没有任何开关要拨。
- 真正决定你读不读报纸的是那个报箱：不造它就没有阅读入口，天数照常在走，
  你随时改主意造一个都来得及。
