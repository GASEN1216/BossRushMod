## 游戏模式总览

八种模式，八种玩法。从休闲打 Boss 到被 Boss 追着打，再到“越打越针对你”的宿命复仇、只押注不下场的擂台经理人，还有独立的丧尸生存，总有一款适合你。

### 一张表看明白

- **标准 BossRush** — 带张船票就能进 / 有限波次 / 打完一波换一波，经典竞技场体验 / 难度 ★★☆☆☆
- **无间炼狱** — 船票 + 选无间炼狱难度 / 无限波次 / Boss 越来越强，活到哪算哪 / 难度 ★★★★☆
- **白手起家** — 裸装 + 船票 / 无限波次 / 随机发装备，从捡垃圾开始逆袭 / 难度 ★★★☆☆
- **划地为营** — 裸装 + 营旗 / 没有波次（沙盒） / 选阵营、拉帮派、Boss 大乱斗 / 难度 ★★★☆☆
- **血猎追击** — 裸装 + 船票 + 血猎收发器 / 四个阶段 / 进去就开始掉血，不杀就死 / 难度 ★★★★★
- **宿命回响** — 当前装备 + 船票 + 宿命回响信物 / 九波三幕 / 反制你的打法，追猎你的宿敌 / 难度 ★★★★★
- **末日丧尸模式** — 尸潮邀请函 / Roguelite 生存 / 裸装入场、无尽尸潮 + 污染递增 + 净化点数经济，独立于以上七种模式 / 难度 ★★★★☆
- **百战留痕（黑市鸭王杯）** — 一张船票，在基地找「Boss Rush」旁边那个选项 / 一季六场 / 你不下场：签两名斗士替你打，你负责看盘口、下注、每场喊一次口令 / 难度 ★★★☆☆

### 身上东西太多？系统帮你选

同时带了好几种入场道具？别慌，系统会按优先级帮你判定进哪个模式：

- 1. **划地为营** — 背包里有营旗？那就是划地为营
- 2. **血猎追击** — 有血猎收发器 + 船票？欢迎来到地狱
- 3. **宿命回响** — 有宿命回响信物 + 船票，且没有血猎收发器？带着自己的装备上场
- 4. **白手起家** — 裸装 + 只有船票？白手起家走起
- 5. **标准 BossRush** — 啥都没带就一张船票？经典模式伺候

百战留痕不在这份清单里：它和标准 BossRush 一样只需要一张船票，没有专属入场道具，在基地「Boss Rush」旁边选「黑市鸭王杯」即可。

### 通用规则

- 标准 BossRush、无间炼狱、白手起家、划地为营、血猎追击、宿命回响这六种，9 张地图随便挑；百战留痕只有 DEMO 终极挑战一张图（地图选择页会自动只列能用的）；末日丧尸走自己的入场流程，不吃这份地图表
- 竞技场里有弹药商店、维修站和垃圾桶——基础设施齐全，不至于弹尽粮绝
- 标准 BossRush、白手起家和血猎追击杀 Boss 掉箱子；无间炼狱改发现金；划地为营只有打敌对阵营才掉；宿命回响只在第 9 波胜利后发放严格奖励
- 末日丧尸模式是**独立的生存模式**：不走船票入场，用净化点数自成一套经济，具体规则见「末日丧尸模式」页面

[tip] 标准 BossRush、无间炼狱、白手起家、划地为营、血猎追击这五种模式在开局时会随机抽取「变异词条」，改变本局的敌人/玩家/环境规则。宿命回响（九波编排是固定的）、百战留痕（盘上写什么场上就是什么）和末日丧尸（另有一套局内奖励）都不抽。详见「变异词条系统」页面。
