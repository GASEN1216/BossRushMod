## 词缀锻造

### 这是什么

重铸改的是**数值**——多几点护甲、多一点射速。词缀锻造改的是**行为**：
让你的枪在击杀时把尸体炸开，让你的刀每一下都吸血，让你的护甲把伤害弹回去。

同一件装备可以同时有重铸属性和词缀，两套系统互不干涉。

- 一共 **12 条**词缀，分三档：普通、稀有、**诅咒**。
- 支持**枪械、近战武器、护甲、头盔、面罩**。图腾和背包不行。
- 诅咒档每一条都是「换」，不是「白拿」——强得明显，代价也写得明明白白。

### 怎么用

- 找叮当，选 `词缀锻造`。
- 选一件装备，花 **1 颗词缀熔石 + 一笔钱**随机打一条词缀上去。
  钱走的是重铸那条价格曲线，所以叮当好感度的折扣一样管用。
- 装备能带几条看它的**品质**：品质 4 及以下 **1 条**，品质 5～6 **2 条**，品质 7 及以上 **3 条**。
  槽位在第一次锻造时就定死，之后不会再变。
- 满意的那条可以**上锁**（花 `2` 颗熔石），再重随机时锁住的不动，只重掷没锁的。**解锁免费**。
- 词缀名会直接显示在装备详情页上，一眼能看出这把枪身上挂了什么。

#### 抽到什么档，是有概率的

- 档位：普通 `62%`、稀有 `30%`、诅咒 `8%`。
- 每条词缀还有三级强度：T1 `60%`、T2 `30%`、T3 `10%`。

所以「稀有档的 T3」大约是 `3%` 的事，「诅咒档的 T3」不到 `1%`。
下面表里给的是 **T1 / T2 / T3** 三个档的数值，你抽到的多半是最左边那个。

### 熔石哪来

- **叮当商店** — 好感度 Lv.2 解锁，每次刷新最多 5 颗。这是稳定线。
- **Boss 掉落** — 约 `8%`，一局标准竞技场大概能捡到一颗。这是运气线。
  熔石**掉在 Boss 身上**，不在战利品箱里，和遗种蛋一样要搜尸。
  覆盖标准三档、白手起家、划地为营、血猎追击；宿命回响、百战留痕和末日丧尸不掉。

两条线都不足以让你无限重随机——这是有意的。熔石紧，你才会认真想「这条要不要锁」。

### 词缀一览

每条词缀只能打在特定类型的装备上，下面标在名字后面。

#### 普通档（5 条）

- **汲血**（武器）— 命中敌人回复最大生命的 `0.6% / 1.0% / 1.5%`，冷却 0.4 秒。
  霰弹一次开火只算一次，别指望一枪回满。
- **屠戮**（全部）— 击杀回复最大生命的 `3% / 5% / 8%`。没有冷却，清杂兵时的续航很舒服。
- **磐石**（护甲/头盔/面罩）— 受击后 4 秒内获得 `1 / 2 / 3` 点护甲，最多叠 3 层。挨得越密越厚。
- **迅手**（**仅枪械**）— 击杀后 5 秒内换弹速度 `+15% / +25% / +35%`，最多叠 2 层。
  连杀时几乎不用等换弹。近战武器打不出这条。
- **荆棘**（护甲/头盔/面罩）— 受击时把本次实际伤害的 `10% / 18% / 28%` 弹回攻击者，冷却 0.35 秒。

#### 稀有档（4 条）

- **殉爆**（全部）— 击杀时引爆尸体，`35 / 55 / 80` 点火焰伤害，半径 `2.5 / 3.0 / 3.5` 米。
  **不会伤到你自己**，可以贴脸炸。
- **狂潮**（全部）— 击杀后 6 秒内射速与机动性各 `+4% / +6% / +9%`，最多叠 5 层。
  叠满是 `+20% ~ +45%`，杂兵堆里越打越快。
- **鹰目**（武器）— 常驻：枪械与近战暴击率各 `+4% / +7% / +11%`。不用触发，拿着就有。
- **灌能**（武器）— 命中时追加一次电击，伤害为本次实际伤害的 `12% / 20% / 30%`，冷却 0.25 秒。

#### 诅咒档（3 条，强力但有代价）

三条都能打在任何支持的装备上，效果也都是常驻的——只要拿着或穿着就在生效。

- **狂血** — 全部武器伤害 `+10% / +16% / +24%`，但生命上限 `−12% / −18% / −25%`。
- **玻璃炮** — 全部武器伤害 `+15% / +24% / +35%`，但护甲 `−1 / −2 / −3` 点。
- **死契** — 击杀回复最大生命的 `10% / 14% / 20%`，但每秒流失最大生命的 `0.8% / 1.2% / 1.8%`。
  **它不会把你耗死**——最低给你留 1 点血，而且在基地里不流失。

[tip] 注意「全部武器伤害」是真的全部：狂血打在头盔上，照样加你手里那把枪的伤害。所以诅咒档往护甲头盔上打是划算的——伤害照拿，武器槽还能留给别的。

[tip] 诅咒档的正确用法是配一套：狂血 + 玻璃炮堆到 `+59%` 伤害，然后靠死契或屠戮把血续回来。要么全押，要么别碰——半吊子只会又脆又没伤害。

### 几个你可能会问的问题

- **词缀只在我拿着的时候生效吗？** 是。武器词缀只在你手持那把武器时生效，护甲词缀只在穿着时生效。
  放仓库或背包里的装备不会有任何效果。
- **NPC 拿着同款武器会触发吗？** 不会，只认你自己。
- **重铸会把词缀洗掉吗？** 不会。重铸和词缀锻造互不干涉，一个改属性一个改行为。
- **卖掉再买回来词缀还在吗？** 在。词缀写在物品自身的数据上，跟着物品走。
- **穿两件带同样词缀的装备会叠加吗？** 会。
- **一件装备会重复出现同一条词缀吗？** 不会，同一件上不会打出重复的词缀。
- **末日丧尸模式能锻造吗？** 不能，那边的临时哥布林不提供这个功能。
- **抽到不想要的怎么办？** 把想留的锁上，再花一颗熔石重随机——只有没锁的会重掷。

### 需要开启吗

不需要。词缀锻造随 Mod 默认启用，找哥布林就能用，没有任何开关要拨。
