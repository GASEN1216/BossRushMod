## 局内随机事件「鸭生无常」

### 这是什么

- 打着打着，战场上会冷不丁冒出点事：空投砸下来、血月升起、天上下钱、或者一只根本不该出现的
  Boss 直接闯进来。
- 每个事件都有横幅播报、限定时长，到点自动收场。
- 和变异词条的区别：词条是开局抽定、整局不变；事件是打到一半突然发生的，有时限。

### 会发生什么

| 事件 | 大概是什么 |
| --- | --- |
| **天降横财** | 补给箱从天而降。落地动静很大，会把附近的敌人引过来抢，手慢无 |
| **血月凶兆** | 屏幕泛红，场上敌人集体变强一段时间。期间击杀有额外现金补偿 |
| **不速之客** | 从 Boss 池里随机抓一只额外 Boss 闯进战场。杀掉有额外奖励；拖太久它自己会走 |
| **神秘商人路过** | 限时开张的摊子，卖弹药、medical 和一件随机好货，价格比平时贵 |
| **声东击西** | 你会听到四面八方传来动静，敌人也会被引着乱跑。其实什么都没发生 |
| **鸭王的烟花** | 纯放烟花，零伤害，就是好看 |
| **金鸭雨** | 天上下钱。无间炼狱里现金会自动吸过来，血赚 |
| **鸭群巡游** | 一队鸭子大摇大摆横穿战场，然后走了 |

### 重要：乱入 Boss 不影响波次

「不速之客」刷出来的 Boss **不算在当前波次里**。你不需要杀它才能推进波次，
它也不会因为死了就让波次提前跳过。想打就打，不想打躲着等它走也行。

### 哪些模式会触发

只在 **标准 BossRush、无间炼狱、白手起家** 三个模式里触发。

划地为营、血猎追击、宿命回响、斗蛐蛐、末日丧尸和普通撤离图都**不会**触发——
那几个模式各有自己的节奏和规则，硬塞事件进去只会打架。

### 开关

ModConfig 里可以关掉整个系统（默认开启），也可以调频率档（低 / 标准 / 高），
影响事件间隔和单局最多触发几次。同一时间只会有一个事件在进行。
