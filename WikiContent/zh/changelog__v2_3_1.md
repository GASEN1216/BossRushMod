## v2.3.1

### 发布日期
- 2026-10-07
- 本版为 v2.3.0（2026-10-02）上线后的综合质量与稳定性修复补丁，并对多个系统的易用性与门控做出了重要优化。

### 新增

- **Boss 生命比例滑条**：在 Mod 设置与 ModConfig 中新增「Boss 生命比例」滑条（`BossRush_BossHealthPercent`），范围 10%～200%，默认 100%。支持游戏内即时热更新，仅在 Boss 生成时生效，与波次系数及装备加成按乘法独立叠加；普通小怪、精英怪及随从不受影响。
- **百战留痕自选押注滑条**：鸭王杯解除 20,000 现金固定封顶，新增「自选金额」滑条；上限根据玩家钱包即时余额与本场真实倍率动态精算封顶。计算全面改用 `decimal` 与 `long`，盘口锁定后冻结赔付分子分母，彻底消除大额下注溢出与跨局金额漂移。
- **装备词缀罗马数字规范**：装备界面的词缀等级规范化显示为罗马数字（Ⅰ / Ⅱ / Ⅲ），中英双语即时切换，消除多层文本重复堆叠的问题。

### 优化

- **遗种崽出战范围全面解禁**：遗种巢随从现在可以陪同你进入游戏内所有常规出击地图与模式（包括宿命回响 Mode G 与末日丧尸模式）；全局仅在「百战留痕」观战模式下禁止带崽，防止扰乱擂台对决。
  - 宿命回响中三轴反制仅统计玩家主角直伤，崽的补刀与击杀仍正常走 Boss 死亡结案。
  - 丧尸模式中击杀计数只认本局丧尸标记，随从不干扰波次与奖励结算。
- **基地闲逛防误伤保护**：处于基地安全区时，随从以独立的非战斗实体生成，自动停用战斗 AI，仅保留和平跟随，彻底杜绝在基地误锁或误伤原版及其他 Mod 商人。
- **图鉴击杀身份采集加固**：鸭皇图鉴优先通过能力组件确认 Boss 真实身份，即使被第三方敌人随机模组改写预设名，或在预设清理前夕触发死亡，也能精准录入击杀与图鉴进度。
- **白手起家（Mode D）波次成长平滑化**：修复波次生命缩放因重复累进计算导致后期 Boss 生命指数暴涨的问题，重构为平滑的每波整体乘算（每波固定 +3%）。

### 修复

- 修复划地为营中龙裔遗族冲撞技能误伤同阵营玩家的问题：碰撞伤害判据修正为双方实体的实际敌对关系（`Team.IsEnemy`），追敌时的同营友军不再挨打。
- 修复天空岛场景加载异常导致黑幕卡死、无法退出的缺陷：加载失败后可靠释放激活阻塞与黑幕引用计数，返航失败保留状态并按原租约安全重试，不再覆盖角色状态。
- 修复官方存档写盘抛出 IO 异常后全局 `IsSaving` 锁残留、导致后续存档全部静默拒绝的问题：引入异常包装与重试自愈机制。
- 修复鸭王征程存档故障恢复时因订阅时序倒置丢失已完成章节进度的问题；Jeff 任务客户端在读屏障故障时正确暂停投影，避免重复派发已完成任务。
- 修复第六章终章记名石独白期间若被 UI 中断会导致记名石永久锁死的问题，取消时安全归还召唤权。
- 修复龙皇二阶段召唤护卫龙裔时在 200% 生命比例下登场仅有半血的缺陷。
- 修复丧尸模式 Boss 刷新点落在不可达区域导致敌人发呆不接战的问题，加入就近采样并强制解除休眠。
- 修复门票 ID 回退逻辑中残留的旧 ID，统一对齐正式门票常量 `500001`。
