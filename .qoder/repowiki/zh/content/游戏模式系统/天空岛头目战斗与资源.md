# 天空岛头目战斗与资源

核对日期：2026-09-26。现行实现专题，`COMPAT`。以 `SkyIslandBossRules`、遭遇 owner、各控制器及实际资源验证工具为事实源；本页说明代码机制，不代表实机品质已验收。逐项验收与看图清单见 [2026-09-26 Boss 战斗与资源审查](../../../../../docs/reports/sky-island/天空岛_Boss战斗与资源审查_2026-09-26.md)。整体流程见 [天空岛剧情与持久化](天空岛剧情与持久化.md)。

## 正式入口、生成与掉落

从基地船点进入独立出击图后，`SkyIslandSession` 建立会话，`SkyIslandEncounters` 按玩家接近自动组或装置交互创建敌人。`SkyIslandBossRules.Profiles` 是头目身份、遭遇 ID / 组内序号、原版参照 ID、专属装备和首杀 note 的单一档案表；`SkyIslandBossForge` 读取它并绑定对应控制器。完整清单与当前数量以该表为准。

2026-09-26 共享候选的基础战斗能力改由 `SkyIslandCombatBalance` 的明确原版参照与统一系数管理，`SkyIslandCombatPreset.Apply` 只写独立克隆，且必须在官方 `CreateCharacterAsync` 前调用。普通拾荒者取各自原 source，带队 / 精英 / 剧情敌人按档案或档次选参照；`EnemyTiers` 与 `BossForge` 不再叠旧的血量、伤害、反应倍率。当前生命等有利属性 ×1.5，散布 / 反应时间 / 射击延迟 ÷1.5，保留原夜间比例；能力一起增强不能等同于实战难度只提高 50%。武器、护甲、招式、掉落和官方难度仍参与最终结果，详见当日专项报告的最新数值表。

零号区序章在 `SkyIslandPreludeFlow.SpawnBoss` 独立生成断风游猎·守，也必须在工厂前按 `K3_Relay / 0 / Chief` 走同一个 `CombatPreset.Apply`，不能只给岛内遭遇接线。当前序章守与岛内守同为基础 375 HP，原实体航向仪尸体箱交付、丢失后残骸兜底与帽子掉落仍沿原 owner。`SkyIslandEncounters` 执行夹具逐字提取正式 `SpawnBoss`，以创建时的角色生命验证时序；将数值准备挪到 await 后会转红。

档案覆盖残星匠首、瞭台观星手、悬根猎首、截信人、穗镰、听雨人、蚋笛翁、镜中客和断风游猎的追 / 伏 / 守。S1 蚋笛翁与 F 镜中客仅在官方夜间窗口生成；白天只刷随从、留下带队位，不能在 Forge 中简单跳过夜限定档案，否则这一位会被消耗成普通敌人。

生成仍使用官方角色 preset、尸体箱及经验，解除距离休眠并应用本图导航图。武器不再沿用拾荒者 preset 的随机装配（常是品质 1 的斧头，头目 / 岛主也一样，因为它们同样从拾荒者克隆、`VanillaPresetId` 只供数值参照）：2026-09-30 起 `SkyIslandEnemyArmory` 在官方创建完成后按档次补齐主武器与近战，品质表在 `SkyIslandEnemyArmoryRules`——拾荒者 3–4、精英 4–5、具名对手 / 头目 5–6、岛主 / 噬风 6–7（抽不到退到 3 或 5，不再往下），普通巡守按岛区等级 1–4 走拾荒者档、5 以上走精英档。官方与其它 Mod 的武器都进池、口径不限（本 Mod 自己的 500xxx 不发：龙息、断界戟这类是主角绑定的传说级奖励），过掉落排除标签、全局黑名单、岛上物资池 10 万价值上限，排除控心与粘手物品；枪必须有同口径弹药，装满弹匣；2026-10-01 起手里每一把枪（换上的、达标留下的官方原装、副武器）背包都补到三匣、至少 45 发同款弹药（`EnsureAmmo`，弹种先沿用已装 / 已带的）——官方 `AddBullet` 按 Boss 预设的弹药品质表抽，不少口径抽不到，留下的原装枪打空一匣就反复喊「没子弹了」。2026-10-02 再补三条：退回「这把枪能用的任何弹药」时不设品质上限（`AnyAmmoMaxQuality`，Alex / 蝇蝇队长 / 机械雪人的专属枪品质码 9，旧写法只查 1–7，日志报「这把枪找不到可用弹药」，守钟装置正是机械雪人底模）；达标但怎么都找不到弹药的原装按不达标换枪（`IsDryGun`）；配完弹挂 `SkyIslandAmmoKeeper`，`InvokeRepeating` 每 3 秒看一眼，同款备弹不足一匣就补回，倒下后取消。达标的原装不换，换下的原装直接销毁，换上的武器随官方尸体箱掉落。三条接线：遭遇组在身份层之后、序章守在 Forge 之后、巡守在固定外形之后；候选池随物资池在读条时预热，模块销毁时复位（`SkyIslandEnemyArmoryGuard`，逐位档次见 `SkyIslandEncounters` 执行回归 `ArmoryRegression`）。通常敌人采用 wolf 敌对兜底；三处断风中继的整组采用 bear，与拾荒者互敌。噬风首战 / 回响复用同一个遭遇系统的手动组，不另建刷怪 owner。折翎与失控守钟装置是剧情 Champion 分支，其推进与居民显隐由剧情系统负责，不属于上述自动头目档案。

2026-09-28 起，自动组通过 `SkyIslandEnemyTiers.ApplyAi` 关闭强制锁定主角，复用官方感知选敌；手动剧情挑战保留按档次的强制追踪。官方 Blackboard 的 `SearchedEnemy` 绑定到 `AICharacterController.searchedEnemy`，攻击树也读取该字段；此前每帧强制写回主角会覆盖正常选中的断风或拾荒者，且无遮挡时战斗树不会重新搜索。此处仅改生成时的选敌策略参数，不改视力、听力、阵营、导航或解除距离休眠的安全网，也不增加每帧扫描。

同日新增 `SkyIslandExplosionBufferPatch`，仅在已有天空岛场景句柄门内借换官方 `ExplosionManager` 的工作数组和 Health 去重列表。原八槽缓冲会遗漏第九个重叠接收体；新 owner 挂在 manager 上，无 Update 和静态容器，饱和时倍增直到查询不饱和。每个同步嵌套调用借独立 frame，容量/深度稳定后复用；Harmony Finalizer 在成功、异常和嵌套返回后恢复原数组、列表及层掩码引用，再清理本次角色引用。原方法继续处理阵营、遮挡、去重、冲刺豁免、伤害与特效，离岛不会把扩容写进其他地图的调用状态。

`SkyIslandBossLoot` 在实例 `BeforeCharacterSpawnLootOnDead` 事件中一次性处理专属装备。三名岛主身穿整套，死亡按权重只留 1 件；单件头目允许不掉。选中件补满耐久，其余卸下销毁，没成功穿上的选中件尝试补入尸体库存。首杀只写已有 note，不能拿首杀旗标禁止下一趟掉落。装备数据、同槽兜底、图标和读档配置经 `SkyIslandBossGearConfig` 与现有物品工厂完成。

## 招式的反制必须成立

| 头目 | 机制与应对的现行契约 |
| --- | --- |
| 残星匠首 | 供能桩可打，星焰有独立落点预警；过热让玩家获得反击窗口，破盔 / 破甲削弱对应机制 |
| 瞭台观星手 | 跟踪后锁定；断视线、近身或锁定后出圈均有作用，破镜盔停止标记 |
| 悬根猎首 | 打任一根桩断绊索，根洞亮圈可躲，钻出后有硬直；破面罩延长预警、破甲减慢速幅度 |
| 截信人 | 伸手亮圈后可后退躲开，只偷规则白名单内的岛上耗材 / 工具；逃点物品可追回，低血线丢赃物 |
| 穗镰 | 先清谷仓帮手可降低召援压力；泥可绕开，镰扫起手站定、锁定圆心，破甲延长预警 |
| 听雨人 | 枪声只在洞口范围内累计；离洞、近战或耳罩有明确效果，破其耳罩停落石 |
| 蚋笛翁 | 吹笛期受伤达到门槛可打断，打断后等待必须长于平常冷却；破面罩停止吹笛 |
| 镜中客 | 背后换位点先亮圈，倒影可打碎并使本体失衡；离镜池不再换位，破甲不再留影 |
| 断风追 / 伏 / 守 | 冲锋线及落点圈对应真实方向与落点；两步追击、闪回、单步冲锋可区分；收招硬直与破装减弱保留 |

共用 `SkyIslandBossForge.CreateGroundRing` 必须拒绝非空但 `enabled=false` 的圈。圈不可用时进入控制器的取消技能路径，不能让不可见范围继续伤害。星焰有多个预计算落点时，也只结算实际画出对应圈的点。

穗镰的 `sweepOrigin` 在起手只读一次，`BossAIController.Pause` 让蓄力动作站定；创建圈失败、正常完成和中止收尾都通过 `ResumeSweepAi` 恢复，死亡不恢复。圈与结算使用同一圆心，不重新读取追逐中的本体位置。该修改保留半径、伤害和冷却，通过兑现预警的解法改善公平性。

蚋笛翁 `FluteInterval` 为正常施法冷却，`FluteInterruptedCooldown` 为被打断后的冷却。2026-09-26 取舍为 9 秒 / 13.5 秒；旧打断分支 4.5 秒使主动打断反而增加技能频率，已移除。精确值以规则常量为准，后续调参保持“成功反制有更长窗口”的关系。

## 噬风首战与回响

首战需双航标并从 `Search_E` 装置选择挑战；回响需结局、噬风已经解决、携带核心与风晶，按每趟次数门控。回响只是同一控制器的 echo 模式：保留固定血线、脉冲和提速，增加一波同半径原地余响并采用暖金配色。

首战和回响的 `eyeOrigin` 都在预警开始时固定。预警地圈、灯光与全部脉冲伤害落在这里，即使没有地图父节点也保持同一个世界位置。不能只固定回响而让首战风眼追着本体跑，否则“半径 ÷ 预警秒数”的逃圈判据会漏掉本体追逐速度。圈为 null 或 disabled 时取消这轮伤害并收掉灯和圈；光源不能替代范围边界。

跨多条血线的大伤害仍合并为当前一次风暴，不把未播放相位强制排队。因此玩家文案是“最多四次风暴”，不能承诺任何伤害下固定发生四次。提速按入场基线绝对计算并封顶，不逐相复利叠加。当前原版参照基础 HP 3000，相位仍在入场反应基线上最多额外提高 1.6 倍；在同一难度下反应速度约为原参照的 1.5×1.6=2.4 倍，不再叠旧 1.7 档次倍率。回响支付成功开战后才提交，核不消耗，本趟次数与长期剧情完成旗标各归自己的 owner。

## 倒影、共享特效与资源

`SkyIslandBossProps.CreateDecoy` 烤出角色当前静态外形；不克隆整个角色，防止复制装备 Item / ItemAgent。每次烤制部件有上限，倒影回收时同时销毁 mesh。`AddDecoyPart` 读取源贴图并通过 `BossRushFxMaterials.Get(BossRushFxBlend.Alpha, texture)` 获得共享透明材质，用 MPB 着色；Legacy Tint 写半值抵消片元中的 2 倍乘数。不透明 SodaCharacter 材质仅改 alpha 不足以生成半透明倒影，不能回退为该做法。

通用材质、冲击发射器、慢速修改器和换位辅助都复用现有管线。普通节拍限频，只有蓄力等表现逐帧推进；圈、桩、绊索、泥、倒影和减速在死亡、失效、切图与销毁时清理。装备效果复用穿戴快照，不让仓库或背包内闲置装备触发专属重工作。

装备实际包 `Assets/Equipment/skyisland_boss_gear` 的 `_Item` / `_Model` 基名来自 `GearSpecs`；图标实际位于 `Assets/ui/production_icons`，不能因图标不在装备包便判资源缺失。装备包内 Standard 材质由正式 `EquipmentFactory` 加载路径转换为 `SodaCraft/SodaCharacter`；场景 shader 则必须在实际场景包中具有 URP Deferred 的 GBuffer pass。它们是两条不同的正式渲染链。

资源核验用 `tools/verify_sky_island_bundle_shaders.py`、`tools/verify_unity_resource_release.py`、`tests/UnityTextureImportPolicyGuard.py` 与 `tools/helmet_fit.py --check`，作者工程和 Editor 由 `tools/unity_project_path.py` 定位。打包前保护其他会话资产改动，打包后重新核对作者发布目录、仓库、游戏目录三方 hash。2026-09-26 本轮只改运行时接线，没有重打包；当时具体包体、贴图尺寸、shader 与 hash 记录在专项报告，不作为永久常量。

## 光与声的回执（2026-09-27）

此前全部头目招式无音效、结算无光、换阶段与倒下只有字幕。正式运行时位于 `SkyIsland/`；`SkyIslandImpactFx.cs` 承载光与粒子，`SkyIslandFxAssets.cs` 承载小包加载与招式音效，两者经 `SkyIslandBossForge.ResetStaticCaches` 回到模块销毁清理链：

- `SkyIslandBossSfx`：五种一次性音效 `boss_telegraph / impact / shatter / phase / defeat`（`tools/gen_sky_island_sfx.py` 标准库合成，`--check` 校验，随 `Assets\Sounds` 整树部署）。走官方 `AudioManager.PostCustomSFX` 反射，6 只轮换发声体做 3D 定位；同种 0.08 s 节流、45 m 距离门，文件缺失只警告一次。
- `Flash`（暖琥珀偏色点光，≤4 盏、不投影、复用 `SkyIslandLightFade` 淡出自毁）、`PhaseBurst`、`DefeatBurst`、可调时长的 `SkyIslandImpactRingFade.SpawnWave`。
- 接线点：`SkyIslandBossForge.CreateGroundRing`（材质可用后）响蓄力声；`Detonate` 对 custom 招式补闷响、官方火球招式不重复；`RaiseDefeated` 在剧情回调之前放倒下回执；匠首 / 猎首 / 穗镰 / 噬风跨档放换阶段回执；断风·伏行囊散开与匠首、断风的装备被打穿、镜中客倒影被打碎放碎裂回执；折翎与守钟装置经 `SkyIslandBossVoice.OnDead`（只限无档案者）补倒下回执。
- 守卫 `tests/SkyIslandBossFeedbackGuard.py`（生成表 ↔ 播放表 ↔ 枚举、节流与光预算、全部调用点，内置反向探针）。判定半径、延迟与伤害不变；观感与帧耗时待 owner 实机。

## 验证入口与限制

静态与纯规则入口包括 `SkyIslandBossEcologyGuard`、`SkyIslandStormEchoGuard`、`SkyIslandStormEchoEscapePropertyTest`、`SkyIslandPlayabilityGuard` 及 `SkyIslandStory` 执行回归。修改结构约束时同步守卫并执行真实文件破坏、实跑转红、字节恢复，不通过放宽断言绕过机制变化。

`SkyIslandCombatRuntime` 将生产策略与原样官方方法放入受控 Unity 边界，以实际 Harmony 执行爆炸补丁，并读取真实游戏 DLL 核对字段/API；覆盖自动组与玩家选敌、攻击目标传递、密集目标、原引用恢复、重入、异常与缓冲复用。`SkyIslandEncounters` 负责真实生成入口的参数和清场闭环。此为 L2，物理替身不代表真实 PhysX 顺序、场景几何或帧耗；实际两派互打和密集爆炸仍需 L3。
