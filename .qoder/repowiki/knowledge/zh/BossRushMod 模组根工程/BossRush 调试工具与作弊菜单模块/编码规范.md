- 所有调试入口方法均以 `DevModeEnabled` 作为第一道守卫判断，未启用时直接 return，避免额外开销。
- 对第三方或易变 API 的访问统一包裹 try/catch，并在异常路径中通过 `DevLog` 记录错误而非抛出，保证调试功能不影响主流程。
- 打开调试 UI 前调用“捕获呈现状态”保存 Time.timeScale、Cursor.visible、Cursor.lockState，关闭时严格恢复，防止游戏状态泄漏。
- 调试 UI 显示期间通过 `InputManager.DisableInput/ActiveInput` 配合一个持久化的 GameObject token 来屏蔽游戏输入，隐藏后立即恢复。
- 跨文件共享的调试逻辑以 `partial class ModBehaviour` 的形式拆分到多个 .cs 文件，每个文件聚焦单一功能（如物品生成、NPC 传送、作弊菜单）。
- 对外可见的 UI 文本统一通过 `L10n.T("中文", "English")` 进行本地化，避免硬编码字符串。
