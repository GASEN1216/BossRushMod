本模块以 `ModBehaviour` 的 partial class 形式分散在多个文件中，所有调试功能均受 `DevModeEnabled` / `HardcodedDevModeEnabled` 开关控制，仅在开发模式下激活。
- 生命周期入口：`DebugToolsRuntimeModule` 继承 `BossRushRuntimeModuleBase`，通过 `OnAwake/OnUpdate/OnLateUpdate/OnDestroy` 将帧循环委托给 `ModBehaviour.TickDebugTools/LateUpdateDebugTools`，实现与主模组的解耦挂载。
- 核心调试能力集中在 `DebugAndTools.cs`：注册 `InteractableBase.OnInteractStartStaticEvent` 与 `ItemAgent_Gun.OnMainCharacterShootEvent` 事件监听，输出交互/开枪详情；提供 F5 附近 GameObject 扫描、F6 放置预览复制（含材质高亮与旋转）、右键删除确认、F8/F9/F10/F11 等快捷键。
- UI 子系统按职责拆分：`ItemSpawner.cs`（F2 物品生成器，基于 OnGUI 窗口）、`InventoryInspector.cs`（F11 背包检查，独立 MonoBehaviour 组件，动态附加到 ModBehaviour 所在 GameObject）、`NPCTeleportUI.cs`（F12 NPC 传送，运行时用 Unity UI Canvas/ScrollRect/Button 动态构建）、`F3DebugCheatMenu*.cs`（F3 多页作弊菜单，使用 L10n 本地化字符串与 `InputManager` 输入屏蔽）。
- 运行时状态管理：打开任意调试 UI 时统一执行“捕获呈现状态”（保存 Time.timeScale/Cursor 可见性与锁定状态），显示时暂停游戏并禁用输入，关闭后恢复；场景加载时通过 `SceneManager.sceneLoaded` 回调清理玩家作弊修饰符。
- 依赖方向：本模块单向依赖游戏框架（`Duckov.*`、`ItemStatsSystem.*`、`Cysharp.Threading.Tasks`）与 Unity API，不暴露公共接口给其他模组，仅通过 `ModBehaviour` 内部方法被主模组调用。
- 完整玩法验收：`F3GameplayValidationRunner` 是跨场景常驻串行状态机；`F3GameplayValidationDiagnostics` 负责 Mode D 登记对象、玩家敌对角色和模式自有角色的独立诊断。每次清理最多逐帧等待 2 秒，inactive 自有角色仍计为残留，清理失败立即中止后续用例。
