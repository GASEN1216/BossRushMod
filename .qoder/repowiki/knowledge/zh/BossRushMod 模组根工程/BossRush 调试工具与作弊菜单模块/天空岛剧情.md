# 天空岛剧情 owner

2026-09-08，`COMPAT / SCHEMA+`。天空岛已从纯探索会话扩展独立槽位剧情；源码保留在 `DebugAndTools/SkyIsland/`，由正式地图会话拥有，新增状态不放入 `ModBehaviour` partial。

`SkyIslandStoryRules` 冻结剧情动作前置和互斥结果，`SkyIslandStoryCodec` 复用共享 JSON token / writer，`SkyIslandStoryService` 持有共享槽位存档与保存协调引擎。新增 key `BossRush_SkyIsland_Story_v1`；两航标、四支线、三捷径、折翎、钟守、结局及区域探索各自为持久事实。换槽与删档使会话失效，坏 schema 只读保护。

`SkyIslandStorySaveRecovery` 是离岛保存失败时的短期 owner。成功保存后退订并销毁自身；原地图可卸载，候选状态仍由 recovery 持有。入口必须拒绝同槽 recovery 尚未结束时创建第二份故事 store。独立出击地图允许非基地保存，每次调用 `Tick` 都要传实际战斗安全状态；被推迟的物理写通过同样的安全门重试。

`SkyIslandContent` 经唯一 IO 入口 `JsonDataRegistry` 消费正式 `Assets/Data/SkyIsland/World.json` 的 15 遭遇与 5 进度门，严格校验稳定 ID / marker / 手动挑战类型、完整集合与门条件；错误整表 fallback 并正式日志告警。

遭遇死亡记录是普通 `SkyIslandEnemyRecord`，官方销毁角色不能抹掉清场事实；清场回调直到存档接受才停止，丢失活体仅补未死槽。D/G 航标分别需要主组与 `_02`。正式掉落/经验/魂沿用官方死亡路径，角色创建期间的 preset 留在 async 局部 owner，生成后交给角色组件，角色销毁后延迟释放。天空岛退出不能销毁仍在 CreateCharacterAsync 使用的 preset。

详细规则见 `zh/content/游戏模式系统/天空岛剧情与持久化.md`。生产剧情回归 `SkyIslandStory` 96 条断言、完整遭遇 owner 回归 `SkyIslandEncounters` 28 条断言已通过，均登记于 `tools/run_runtime_regressions.py`；真实 Unity 敌人、交互、门和存盘仍由地图总体 smoke 验证。

## 可玩性复审修复（2026-09-09，COMPAT）

**遭遇按出击刷新**是本轮最重要的一条。原先 13 组自动遭遇全部靠 `clearedEncounters` **永久**
抑制生成，而 39 个搜刮点每趟重刷 —— 第二次进岛起零敌人、约百件产出无限重复。
`Tick` 的短路条件收窄成 `!encounter.Started && encounter.Manual && completed(id)`：
自动组每趟重刷，具名剧情对手（折翎 / 钟守 / 噬风）仍一次性。
**存档 schema 不动**：`clearedEncounters` 对自动组降级为「剧情装置的前置证据」
（D+D_02 修风标、G+G_02 修星灯、S4 校准观星镜），一次达成永久有效。
`RemainingClearable` 必须同步去掉 `!completed(id)`，否则委托侧仍然是死的。

**剧情面板必须有战斗门**。面板走共享模态租约压 `Time.timeScale = 0`，而这个暂停**是可靠的**
（`ModBehaviour.LateUpdate` 排在官方 `TimeScaleManager.Update()` 之后，Unity 保证 Update 全部先于
LateUpdate）—— 没有门它就是战斗中的免费暂停键，且面板里挂着苔药与整备，可以定格战斗再回满血。
`CanOpenStoryPanel` + `HasLivingEnemiesWithin(point, 35f)` 挡打开时机，`WorldStory.Tick` 自动收起。
**按半径不按全图**：`HasLivingEnemies` 是全图口径，把敌人丢在岛的另一头会让全岛剧情交互死锁。

其余：档次倍率改成严格递增（Champion 2.2 → 4.5，原先弱于 Elite 2.6）；噬风 ×18 两相位 →
×13 四相位、预警 9 m/1 s → 7 m/1.4 s（官方爆炸**无距离衰减**，能否逃脱只由半径÷预警决定）；
件数 1–2 / 2–3 / 2–4（原先 Voyage 比 Starworks 还多）；苔药改按缺失血量比例计价 + 300 s 冷却；
谢礼箱按轮次 120° 错开落点（原先三轮全压在苇白/留言板身上）；折翎战败后隐藏并留旧腰牌纪念物；

撤离读条在官方界面打开时**冻结**而非清零；`Scav` 不再改 `nameKey`（保住官方击杀计数）；
`ZhelingPass` 门牌改为如实写「近路」（`A→B→C→D→E→G` 全程无门，折翎可跳过）。

**守卫盲区教训**：上述问题**全部落在守卫没钉住的位置**（三张倍率表、件数、120 m 半径、

## 2026-09-09 可玩性复审第二轮：交互可达性与官方语义

  `TryFindCratePosition`，方位角取标记名稳定散列。
- **官方爆炸遮挡在抬高地形上恒失效**：`ExplosionManager.CheckObsticle` 硬编码射线 y = 0.5，
