# 天空岛剧情 owner

2026-09-08，`COMPAT / SCHEMA+`。天空岛已从纯探索会话扩展独立槽位剧情；源码保留在 `DebugAndTools/SkyIsland/`，由正式地图会话拥有，新增状态不放入 `ModBehaviour` partial。

`SkyIslandStoryRules` 冻结剧情动作前置和互斥结果，`SkyIslandStoryCodec` 复用共享 JSON token / writer，`SkyIslandStoryService` 持有共享槽位存档与保存协调引擎。新增 key `BossRush_SkyIsland_Story_v1`；两航标、四支线、三捷径、折翎、钟守、结局及区域探索各自为持久事实。换槽与删档使会话失效，坏 schema 只读保护。

`SkyIslandStorySaveRecovery` 是离岛保存失败时的短期 owner。成功保存后退订并销毁自身；原地图可卸载，候选状态仍由 recovery 持有。入口必须拒绝同槽 recovery 尚未结束时创建第二份故事 store。独立出击地图允许非基地保存，每次调用 `Tick` 都要传实际战斗安全状态；被推迟的物理写通过同样的安全门重试。

`SkyIslandContent` 经唯一 IO 入口 `JsonDataRegistry` 消费正式 `Assets/Data/SkyIsland/World.json` 的 15 遭遇与 5 进度门，严格校验稳定 ID / marker / 手动挑战类型、完整集合与门条件；错误整表 fallback 并正式日志告警。

遭遇死亡记录是普通 `SkyIslandEnemyRecord`，官方销毁角色不能抹掉清场事实；清场回调直到存档接受才停止，丢失活体仅补未死槽。D/G 航标分别需要主组与 `_02`。正式掉落/经验/魂沿用官方死亡路径，角色创建期间的 preset 留在 async 局部 owner，生成后交给角色组件，角色销毁后延迟释放。天空岛退出不能销毁仍在 CreateCharacterAsync 使用的 preset。

详细规则见 `zh/content/游戏模式系统/天空岛剧情与持久化.md`。生产剧情回归 `SkyIslandStory` 96 条断言、完整遭遇 owner 回归 `SkyIslandEncounters` 28 条断言已通过，均登记于 `tools/run_runtime_regressions.py`；真实 Unity 敌人、交互、门和存盘仍由地图总体 smoke 验证。

独立出击场景的最小官方服务装配由 `SkyIslandRaidLease` 持有，不能依赖随宿主销毁的 Session。
Session 掌握导航初始化屏障、世界 owner 与玩法；取消扫描需先 Dispose 再解除屏障，返航开始停止旧 Build。
宿主在加载中消失后，独立 `SkyIslandRaidRecovery` 继续完成官方加载并安全返基地；死亡则等官方死亡任务。
bundle 释放同时等待实际 Scene 卸载与租约自己的官方加载任务完成。生产租约回归 18 条断言已通过。

## 随官方时钟变化的光照

`SkyIslandLighting` 自建地图日光和 Volume，不使用基地灯模板。`Tick()` 默认按 `GameClock.TimeOfDay.TotalHours` 平滑混合晨光/晴昼/暮色/星夜；Guide 的手动循环包含自动档。只在原 Scene 仍加载且活动时归还 RenderSettings；专用 shader globals 以 owner 标记避免迟到清理覆盖后来会话。实际生产时间混合方法的 64 项边界断言已通过，Unity 画面与过图仍待实机验收。引用：`SkyIslandLighting.cs`、`tests/fixtures/SkyIslandLighting/`。

## 2026-09-09 内容扩充：物资、敌人档次、噬风与居民服务

分类 `COMPAT / SCHEMA+`。交付文档此前把「独有任务物品、商店售价、可重复领取的经济奖励」明确留作后续定稿，
本轮把这块补齐。**没有新增 TypeID，没有重建场景包**：全部内容都挂在已有作者标记与官方物品表上。

**搜刮点 owner**：`SkyIslandScavenging` 由 Session 持有。39 个锚点写在纯逻辑的 `SkyIslandLootTables`
（marker + 极坐标偏移 + 档次 + 区域），进图装配时一次性解析成落点：地面射线、墙体胶囊、
与已有玩法标记 4.5 m 净距、与其它已落位点 3 m 净距，四项任一不过就跳过该点（fail-open）。
按 4.12 门控，玩家进入 72 m 才建箱，**一次 Tick 最多建一个**。三个档次
（生活物资 1–3 / 航务补给 2–5 / 星工遗存 4–7）只决定品质带与件数。

**箱子唯一建造点是 `SkyIslandRewardCrate`**（搜刮点 / Boss 战利品 / 委托谢礼共用），三条约束收在一处：
① 先在**未激活**的暂存父节点下实例化再摘掉官方 `LootBoxLoader`——它的 `Awake` 会按位置哈希随机
`SetActive` 并写 `MultiSceneCore.inLevelData`；② 必须 `EnsureLocalInventory`，官方按位置哈希共享库存，
靠得近的两个箱子会串味；③ `InstantiateSync` 缺资源时返回同 TypeID 的**空壳 FallbackItem**，
既不为 null 也不抛，必须回读 `TypeID` 才能确认。

**物品池唯一查询点是 `SkyIslandLootPools`**，用 `GetAllTypeIds` 而**不是** `Search`——官方 `Search`
在结果为空时会自行降级 quality 反复重搜，会把「星工遗存」悄悄降成杂物。自定义内容靠
`LootBlacklistRegistry` 挡住，`Special` tag 不是可靠护栏。结果必须 `Sort()`：`GetAllTypeIds`
经过 HashSet，顺序不稳定，不排序则同一 seed 在不同机器上抽到不同物品。

**敌人档次**：枚举 `SkyIslandEnemyTier` 单独放在无依赖文件里（内容表与运行时装饰共用，隔离回归只链接它）；
装饰逻辑在 `SkyIslandEnemyTiers`。三层都是可失败装饰，口径同战役「冠军之影」：数值只改 `CharacterItem`
的 stat 且伤害封顶 3；**外观只缩放 `characterModel`，绝不动角色 transform**——碰撞体与导航半径保持官方口径，
体型变化不带来物理/寻路成本；染色走 `MaterialPropertyBlock`，不碰 `sharedMaterial`。
`Champion`（折翎、钟守）**只吃数值与 AI**，保留自己的脸和名字。

**内容表扩展**：`SkyIslandEncounterDefinition` 增加 `Tier` / `Lead` 两个字段，`TierFor(index)` 决定
第 1 名与随从的档次；JSON 按**稳定字符串名**解析（不认序号，将来插档不会让旧表悄悄改语义），
并与内置表逐字段比对。遭遇由 15 组增至 16 组：新增手动组 `Storm`（marker `POI_E`，3 名 = 噬风 + 2 名断风游猎）。
D / G / S4 的带队者升为 `Elite`；Zheling / BellKeeper 升为 `Champion`。

**噬风**：`SkyIslandStormBoss` 挂在带队者身上。本体就是遭遇系统的一个手动组，因此天然吃 12 活体上限、
本图 graphMask、关闭距离休眠与官方掉落/经验，不另开生成路径。相位阈值 0.66 / 0.33，
**预警 1 秒**后三波范围伤害并提速；自建伤害显式 `canHurtSelf:false` + `isFromBuffOrEffect:true` +
`fromWeaponItemID:0`，脉冲一律由协程发起，不在 `OnHurt` 期间嵌套爆炸。

**SCHEMA+**：新增 flag `StormSlain = 32768`，`KnownFlags` 由 32767 提到 65535。旧档读出来为 0，
语义即「尚未挑战」。Codec 增加不变式：`StormSlain` 而 `!BothBeacons` 视为坏数据整份拒绝。
**击败噬风是说服钟守的第五条路线**——原路线要求旧信 + 航路图 + 观星镜 + 折翎和解四件齐备，门槛过高。
