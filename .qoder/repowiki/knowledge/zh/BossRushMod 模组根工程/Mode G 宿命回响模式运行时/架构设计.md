## 2026-09-25 入口服务归位（SAFE）

`ModeGEntryRuntime` 持有原入口的 active、每局 core、HUD、preview、契约选择及原静态会话/玩家标识缓存。`ModeGEntryHostBridge` 惰性创建服务，完成六组窄委托绑定后才发布；Legacy、Mode D/E/F、Zombie 状态、热键配置、Boss preset 缓存和竞技场状态通过即时查询/写入回调连接原宿主。服务没有新的宿主业务字段，也没有注册为模块。旧公开/internal 入口和 F3 使用的 private `StartModeGRuntime` 保留直接薄桥；空闲 `UpdateModeG`、`ShutdownModeG` 不因调用而创建服务。

注册处的 shell 与入口每局 `new ModeGRuntimeModule()` 是两个独立来源。注册 shell 的 `OnUpdate` 仍先检查 `ModeGRunContext.CurrentModule != this`；真实核心由原宿主 tick 链驱动：`ModBehaviour.Update` 先调用 `runtimeModuleHost.OnUpdate`，再进入 `TickModeRuntimeGroup`，在 Mode F 后、Zombie 前经过宿主 `UpdateModeG` 薄桥。服务内维持热键 → core.Update → HUD.Update → 终态关停，HUD、入口和 RunContext 引用同一局核心。场景清理仍先 `End(SceneChanged)` 再 Shutdown，每局 Dispose 后不复用。

退款仍按原责任边界：消费信物与船票/接管预扣票后启动，Starting 与 RunContext 绑定成功后由 `ArmStartupRefund` 接管；外层仅在未移交时退款。单局 Shutdown 不清空服务的宿主委托，因为原异步生成和 handle 可能晚于关停返回。官方生成桥在 await 前冻结 state，迟到对象仍归旧 state；handle 的激活/清理委托保留原宿主，不能改查新 `ModBehaviour.Instance`。三个托管 adapter 在 await 后重验 owner，失效结果调用 `CleanupOnce(OwnerInvalid)`。

静态归属由 `tests/ModeGEntryOwnershipGuard.py` 钉住；`PersistentHudVisibilityGuard` 沿完整宿主 → 服务 → HUD 链检查驱动。`tests/fixtures/ModeGEntryOwners` 完整编译五个入口生产文件、真实 RunState/RunContext/生成契约，仅替换 Task 载体和外部依赖，覆盖双局、退款、时序与迟到工厂。核心战斗继续由 ModeGCombat 验证；入口夹具不证明 Unity 调度、实际资源交付或 HUD 视觉。证据为 L1/L2，未新增 L3 实机结论。

## 2026-10-13 联机共享波次与个人运行（COMPAT / WIRE+）

频道由稳定的 ModeGEntryRuntime 持有，每位玩家实际创建自己的 ModeGRuntimeModule。共享 run 身份、场景、生成计划、波次和 Boss 实体来自房主；票、信物事务、快照、个人契约候选、遥测、Resolve、档案与宿敌继续走本人的既有服务。所有握手玩家按 SceneID / runId / wave 准备，且前一波个人收据已确认后，房主才激活本波实体。客端按原生 AI ID 登记共享 Boss，不另行生成敌人。

伤害事实由房主读取原生护甲后伤害与真实玩家来源，按收件人连续序号递送；客端跳过原生同步回调。乱序消息等前序，重发幂等；本人直伤才进入评分，他人末击仍推进共享波次的 Boss 结案。个人死亡回执记录本人败北和宿敌归因；房主本人倒下而其他人存活时保留共享世界，待全员失败才结束世界。

入口等待与实际 run 都冻结本人资产身份。客端切换槽后旧个人 run 按场景离开结束；房主切槽撤销自己的个人资格并恢复 Modifier，保留队友共享世界和 Boss。两者都取消本局启动退款资格，个人遥测和成就不再写入新槽；船票旧义务由地图入口的本人资产租约持有，切回原槽才交付。遥测保持未激活、空 Health、未登记 Health 的 O(1) 三级早返。客端明确 Boss 镜像接 [预测生命保护](file://Utilities/CoopAiPredictionHealthProtection.cs)，本机预测不能触发原生 99999 强制致死，房主仍按真实护甲结算，真实死亡快照放行。`ModeGCombat` L2 还执行了换槽终止/不重复终止/旧收据拒绝，不能将这些结果提升为真实存档或九波实机验收。
