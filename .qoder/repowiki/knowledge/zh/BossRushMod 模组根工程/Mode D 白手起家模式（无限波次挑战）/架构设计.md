本模块以 `ModBehaviour` 为统一宿主类，通过 C# partial class 将功能按职责拆分为多个文件：
- `ModeD.cs`：核心状态机与生命周期管理，维护 `modeDActive`、`modeDWaveIndex`、各物品池（武器/护甲/头盔/弹药/医疗/近战/图腾/面具/背包）及按品质分桶的字典，负责启动 (`StartModeD`)、结束 (`EndModeD`)、裸体检测 (`IsPlayerNaked`)、物品池初始化 (`InitializeModeDItemPools`)、敌人池扫描 (`InitializeModeDEnemyPools`)。
- `ModeDEquipment.cs`：装备系统，含敌人配装 (`EquipEnemyForModeD`)、基于质量分桶的随机选择 (`GetRandomItemByQuality`、`PickBossRushStyleBucketItemId`)、以及一个分阶段的状态机 `SharedModeEnemyEquipmentMaterializationPlan` + `SharedModeEnemyEquipmentPlanPhase` 用于延迟实例化敌人掉落物并捕获 `UnityEngine.Random.state` 保证跨 yield 的 RNG 一致性。
- `ModeDEquipment_StarterKit.cs`：玩家开局装备发放流水线 (`GivePlayerStarterKit`)，按固定顺序发放武器→弹药→护甲→头盔→近战→医疗→图腾→面具→背包，并通过 `EnsureStarterGunHasBulletType` / `FillGunMagazine` 自动匹配口径弹药并填满弹夹。
- `ModeDWaves.cs`：波次管理，定义 Boss/小怪配比规则（1-5 全小怪、6-10 一 Boss、11-15 两 Boss、16+ 全 Boss），使用协程 `SpawnModeDWaveEnemiesCoroutine` 分帧生成以避免低端机帧尖刺，并通过 `modeDExpectedEnemiesInCurrentWave` / `modeDSpawnResolvedInCurrentWave` 双计数 + `TryResolveModeDWaveComplete` 确保波次完成判定不被“迟到”的异步生成任务破坏；同时提供每波 3% 的属性缩放 (`ApplyModeDWaveScaling`) 和周期性完整性自检 (`TickModeDIntegrity`) 防止卡关。
- `ModeDInteractables.cs`：运行时注入路牌交互选项，定义 `ModeDNextWaveInteractable` 组件并通过反射写入 `otherInterablesInGroup` 列表挂载到 `bossRushSignInteract`，支持“冲下一波”、清空箱子等 UI 操作。
- `ModeDRuntimeModule.cs`：继承 `BossRushRuntimeModuleBase` 的轻量运行时模块，仅转发 `OnUpdate` 到 `owner.TickModeDIntegrity`，作为框架钩子接入主循环。
- `ModeDGlobalLoot.cs` / `ModeDGlobalLootStaticCacheReset.cs` / `ModeDStaticCacheReset.cs`：全局掉落池与静态缓存重置逻辑，避免跨局污染。
- 敌对与退出不变式：生成完成回调在登记前强制并回读 wolf 敌对状态，失败对象不进入波次表；`EndModeD` 对活动和已提前关闭两种状态都确定性注销恢复、禁掉落并销毁登记实体，重复调用幂等。
依赖方向单向指向游戏核心 API（`CharacterMainControl`、`ItemAssetsCollection`、`GameplayDataSettings.Tags`、`BossRushLootboxUtility` 等），模块内部无外部依赖，所有跨文件协作均通过 `ModBehaviour` 的字段与方法暴露。
