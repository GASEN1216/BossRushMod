本模块是纯验证层，不包含任何运行时游戏代码，分为三类子体系：
- Python 静态守护（`tests/*.py`）：每个文件对应一条具体 invariant（如 `StaticCacheLifecycleGuard.py`、`EmptyCatchGuard.py`、`ZombieMode*Guard.py`、`PhantomWitch*Guard.py`、`DragonKing*Guard.py` 等），通过 `rglob("*.cs")` 扫描项目源码并执行正则匹配；失败时输出非零退出码。
- 白名单/预算文件（`tests/*.txt`）：`static_cache_allowlist.txt`、`empty_catch_budget.txt`、`large_file_existing_allowlist.txt`、`event_subscription_lifecycle_allowlist.txt`、`no_hardcoded_map_fallback_enforced.txt`、`find_objects_hot_path_allowlist.txt` 等作为可配置的豁免清单或配额上限，由对应 Guard 读取。
- C# 独立测试工程（`*.csproj` + `*.cs`）：使用 `Microsoft.NET.Sdk`、`net8.0`、`EnableDefaultCompileItems=false`，仅编译单个测试文件并通过 `<Compile Include="..\Utilities\*.cs" Link="...">` 链接被测工具类，脱离 Unity 进程运行。
- 辅助工具：`SmokeLogScan.py` 扫描游戏最新 `.log` 中 BossRush 相关错误块，支持 `DUCKOV_GAME_PATH` 环境变量与 Windows 路径归一化。
- 入口约定：所有守护脚本以 `if __name__ == "__main__": sys.exit(main())` 暴露 CLI，统一返回 0=通过、非 0=失败；全量执行命令为 `for %f in (tests\*.py) do python %f`。
依赖方向单向：Guard → 项目根目录下的 `*.cs` 源码，不反向引用游戏 DLL。
