- 每个守护脚本实现 `main() -> int` 并以 `sys.exit(main())` 暴露 CLI，统一以退出码 0/非 0 表达 PASS/FAIL。
- Guard 通过 `PROJECT_ROOT = Path(__file__).resolve().parent.parent` 定位仓库根，再 `rglob("*.cs")` 扫描源码，排除 `Build/.git/tests` 等目录。
- 对无法立即修复的遗留问题采用外部文本白名单（`*_allowlist.txt` / `*_budget.txt`）而非在代码中硬编码豁免。
- C# 测试工程使用 `EnableDefaultCompileItems=false` 显式声明被编译文件，并通过 `<Compile Include="..\Utilities\Xxx.cs" Link="Xxx.cs">` 链接被测工具类，保持测试与源分离。
- Guard 命名遵循 `<领域><关注点>Guard.py` 模式（如 `ZombieModeSpawnEnemyCoreReuseGuard.py`、`PhantomWitchScytheSwingFxParticleLookupGuard.py`），一个文件只断言一条 invariant。
- 静态分析使用正则表达式匹配 C# 结构（如 `private static Dictionary<`、`ResetStaticCaches` 调用），并在注释/字符串中忽略匹配以避免误报。
