入场条件：配置项 `modeHEnabled`（ModConfig 键 `BossRush_ModeHEnabled`，默认关闭）+ 内容就绪 + 地图支持 + 展示资源就位 + 无旧模式冲突 + 生产认证通过；任一不满足都 fail-closed 拒绝并**恰好退还一张**预扣船票（`ModeHEntry.TryRefundPrepaidTicket()` 是唯一退款实现点）。

**没有真实资产开关**：`modeHRealWarehouseStakeEnabled`、`IsModeHRealWarehouseStakeConfiguredEnabled`、`GatePassed` 三个符号一律不得出现；系统唯一会自行禁用押品的情况是只读派生结果 `ModeHWarehouseStakeJournal.IsSlotConsistent` 为假。同意通过“进入模式”表达，入口页、模式说明与 `ModeHInteractable` 三处固定显示 `BossRush_ModeH_RealStakeRiskNotice`。

冻结常量（`ModeHConfig`）：六场 / 每场 180 秒 / 生产目录 8–12 个 key / 逐 key 认证 15 秒、全池 180 秒 / 口令窗口 6 秒 / 重申间隔 0.1 秒 / 快照间隔 10 秒 / 看台半径 3.0 米、重设 0.5 秒、连续失败上限 3 / ERROR 触发 8%、控制切换 deadline 2 秒 / 虚拟筹码初始 6、上限 30、每场至多 2 / 奖励候选上限 3 / 战痕上限 3、名声上限 99 / 名人堂上限 32 条 / 威胁走廊 `100,115,130,145,165,190`、同屏上限 `2,2,3,3,3,3` / 计划候选重试上限 8。

存档 key 冻结为三个 v1：`BossRush_ModeH_Season_v1`、`BossRush_ModeH_HallOfFame_v1`、`BossRush_ModeH_StakeJournal_v1`。编译期开发门 `ModeHAvailability.AllowDevRawPngFallback` 与 `AllowDevControlPointHarness` 恒为 `false`，不进配置与存档；后者门控只读诊断入口 `ModeHControlPointHarness`（控制点保持率、单点读数、物品目录 dump），它不创建 Season、不写存档、不发奖励、不消耗船票。

展示资源 `Assets/ui/modeh_presentation` 是 local-only 制品，由兄弟 Unity 工程 `Assets/Editor/ModeHPresentationBundleBuilder.cs` 生成后复制；两个 bat 在缺包时明确失败或把 Mode H 标成不可用，不静默打包。
