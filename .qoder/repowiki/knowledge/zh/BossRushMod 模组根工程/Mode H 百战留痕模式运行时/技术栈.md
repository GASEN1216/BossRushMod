Unity C# 模组（命名空间 `BossRush`，C# 7.3），确定性随机源为 FNV-1a 64 + SplitMix64（`ModeHSeedStream`，按 domain/sequence 派生，概率量化到百万分之一整数，禁用全局随机）；规范摘要为 SHA-256 + 自实现 canonical JSON（`ModeHCanonicalDigest` + `ModeHJsonValue`，ordinal 属性排序、集合字段排序去重、拒绝 NaN/Infinity），三签名为 `gameBuildSignature`/`modBuildSignature`/`contentCatalogSignature`。持久化走原生 `Saves.SavesSystem` typed API 的三个 v1 key，写盘由 `ModeHSaveFlushCoordinator` 统一批处理（全模块只有一个 `SaveFile(false)` 调用点）。角色生成直接调用官方 `CharacterRandomPreset.CreateCharacterAsync`（UniTask），不经 `EnemySpawnCore`。UI 复用 `Common/UI/BossRushUI.cs` 门面与 `ZombieModeUIHelper`（TextMeshPro，官方 `GameplayDataSettings.UIPrefabs` 优先），本地化走 `L10n.T` + `LocalizationHelper.InjectLocalizations`。Harmony 只用两个 postfix。
