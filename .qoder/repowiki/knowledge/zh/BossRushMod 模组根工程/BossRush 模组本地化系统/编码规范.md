- 所有显示文案以成对的中英文常量（如 `XXX_CN` / `XXX_EN`）声明在注入器或装备类中，再通过 `L10n.T(cn, en)` 根据当前语言选择。
- 每个可本地化的实体都提供独立的 `InjectXxxLocalization(...)` 方法，并在内部同时注册中文键、英文键、`BossRush_*` 业务键以及 `Item_{typeId}` / `Buff_{id}` 等运行时键。
- 批量 UI 文案通过 `Dictionary<string,string>` 构造后用 `LocalizationHelper.InjectLocalizations` 一次性注入，避免重复 try/catch。
- 长段对话数据以 `string[][]` 二维数组存储，每行 `[cn, en]` 一对，注入时用 for 循环按索引生成 `BossRush_*_Dialogue_i` 键。
- 所有对 `LocalizationManager` 的调用均包裹在 try/catch 中，并通过 `ModBehaviour.DevLog` 输出错误信息，保证注入失败不中断模组启动。
- 部分类 `LocalizationInjector` 被拆分为 `LocalizationInjector.cs` 与 `LocalizationInjector_NpcUiAndItems.cs`，按功能域（核心数据 vs NPC/UI/物品）拆分但共享同一 static class 名。
