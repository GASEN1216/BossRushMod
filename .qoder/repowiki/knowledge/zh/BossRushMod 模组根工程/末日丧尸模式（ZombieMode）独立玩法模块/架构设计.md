本模块以 `ModBehaviour` 的 partial class 形式嵌入宿主 Mod，通过 `ZombieModeRuntimeModule`（继承 `BossRushRuntimeModuleBase`）作为运行时挂载点，由 `ZombieModeEntry.cs` 中的 `zombieModeRunState`（`ZombieModeLifecyclePhase` + `ZombieModeCombatPhase` 双状态机）驱动整个 run 生命周期：SelectingMap → Prechecking → CommittingResources → LoadingMap → InitializingRun → WaitingStarterChoice → Active → Exiting。

内部按职责拆分为多个 partial 文件：
- 入口/生命周期：`ZombieModeEntry*`（入场预检、资源暂扣与退款、场景加载协调、run 初始化）；
- 数据模型：`ZombieModeModels.cs` 集中定义所有枚举、`ZombieModeRunState`、`ZombieModeOptionRuntimeState`、`ZombieModeTemporaryNpc`、`ZombieModeRewardNode`、Boss SkillState 多态基类及子类（Titan/Hunter/Splitter/Shielder/Corruptor）；
- 战斗循环：`ZombieModeWaveController`（注册 Health.OnDead/OnHurt 事件监听、安全区攻击取消、伤害吸收回血）、`ZombieModeSpawner`（刷怪点收集与去重网格、敌人/精英/Boss 生成）、`ZombieModeBossController`（Boss 技能调度）；
- 奖励系统：`ZombieModeRewards` + `ZombieModeRewardCatalogAndSelection` + `ZombieModeRewardEffects*` + `ZombieModeRewardItemGrants` + `ZombieModeRewardNpcServices` + `ZombieModeRewardPreparationDuration` + `ZombieModeBackpackJunkRecycle` + `ZombieModeRewardTriggerEffects` + `ZombieModeRewardProjectilePatch|Spread` + `ZombieModeRewardRuntimeModifiers` + `ZombieModeRewardOptionCore`，按类型分文件并通过 `ZombieModeRewardType` 枚举统一分发；奖励界面默认只展示休息时长和 Edit，展开后按 15 秒步进选择 15～300 秒，状态存于 `ZombieModeRunState.SelectedPreparationDurationSeconds`，初始 45 秒且跨波次沿用；
- 经济与交互：`ZombieModeCashInvestmentView`、`ZombieModeInventoryTransfer`、`ZombieModeMapIsolation`、`ZombieModeSafeZoneController`、`ZombieModeExtractionController`、`ZombiePurificationPointController`；`PortableSafeZoneDevice` 在 Combat/Preparation/ExtractionOpportunity 阶段可用，安全区按主槽（正常区，带商人）与便携副槽双槽管理：战斗期使用便携装置会替换主槽安全区，本波结束后由准备期流程重新生成带商人的正常安全区；准备期使用则写入独立副槽，与带商人的正常安全区并存，两槽在下一波开始时一起清除；替换主槽时旧视觉、地图 POI 与安全区绑定临时 NPC 会先清理并重新登记到 run-only，写副槽时不回收主槽绑定的服务 NPC；玩家在任一区内用枪械或近战直接伤害丧尸会同时取消两槽（手雷、投掷物与玩家来源的奖励弹道不触发）；新安全区启用后立即清除区内非 Boss 丧尸、把 Boss 移到边界外，并由生成回调与周期 Tick 共同维持丧尸禁入；
- 污染机制：`ZombieModePollution` + `_RuntimeComponents` + `_RuntimeSkills`；
- 辅助：`ZombieModeTuning`（数值配置）、`ZombieModeUIHelper`、`ZombieModeDebug`、`ZombieModeCleanup`、`ZombieModeEnemyRuntime`、`ZombieModePlayerSlowRuntime`、`ZombieModeNpcCatalog`、`ZombieModeMapSelection*`。

依赖方向单向：Entry → Wave/Spawner/Boss/Rewards/Economy/UI/Cleanup；所有运行时对象通过 `ZombieModeRunOnlyRecord` 登记到 run-only cleanup 通道，确保场景切换时自动销毁。模块明确不接入标准 BossRush 共享 mutator roll，使用自身 reward catalog 与选项体系。便携安全区物品 TypeID 固定为 `500058`，AssetBundle 名建议为 `portable_safe_zone_device`，Prefab 名建议为 `BossRush_PortableSafeZoneDevice`，缺少资源包时由配置类提供运行时兜底注册。
