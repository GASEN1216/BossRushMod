本模块以 `ModBehaviour` 的 partial class 形式嵌入宿主 Mod，通过 `ZombieModeRuntimeModule`（继承 `BossRushRuntimeModuleBase`）作为运行时挂载点，由 `ZombieModeEntry.cs` 中的 `zombieModeRunState`（`ZombieModeLifecyclePhase` + `ZombieModeCombatPhase` 双状态机）驱动整个 run 生命周期：SelectingMap → Prechecking → CommittingResources → LoadingMap → InitializingRun → WaitingStarterChoice → Active → Exiting。

内部按职责拆分为多个 partial 文件：
- 入口/生命周期：`ZombieModeEntry*`（入场预检、资源暂扣与退款、场景加载协调、run 初始化）；
- 数据模型：`ZombieModeModels.cs` 集中定义所有枚举、`ZombieModeRunState`、`ZombieModeOptionRuntimeState`、`ZombieModeTemporaryNpc`、`ZombieModeRewardNode`、Boss SkillState 多态基类及子类（Titan/Hunter/Splitter/Shielder/Corruptor）；
- 战斗循环：`ZombieModeWaveController`（注册 Health.OnDead/OnHurt 事件监听、安全区破隐、伤害吸收回血）、`ZombieModeSpawner`（刷怪点收集与去重网格、敌人/精英/Boss 生成）、`ZombieModeBossController`（Boss 技能调度）；
- 奖励系统：`ZombieModeRewards` + `ZombieModeRewardCatalogAndSelection` + `ZombieModeRewardEffects*` + `ZombieModeRewardItemGrants` + `ZombieModeRewardNpcServices` + `ZombieModeRewardTriggerEffects` + `ZombieModeRewardProjectilePatch|Spread` + `ZombieModeRewardRuntimeModifiers` + `ZombieModeRewardOptionCore`，按类型分文件并通过 `ZombieModeRewardType` 枚举统一分发；
- 经济与交互：`ZombieModeCashInvestmentView`、`ZombieModeInventoryTransfer`、`ZombieModeMapIsolation`、`ZombieModeSafeZoneController`、`ZombieModeExtractionController`、`ZombiePurificationPointController`；
- 污染机制：`ZombieModePollution` + `_RuntimeComponents` + `_RuntimeSkills`；
- 辅助：`ZombieModeTuning`（数值配置）、`ZombieModeUIHelper`、`ZombieModeDebug`、`ZombieModeCleanup`、`ZombieModeEnemyRuntime`、`ZombieModePlayerSlowRuntime`、`ZombieModeNpcCatalog`、`ZombieModeMapSelection*`。

依赖方向单向：Entry → Wave/Spawner/Boss/Rewards/Economy/UI/Cleanup；所有运行时对象通过 `ZombieModeRunOnlyRecord` 登记到 run-only cleanup 通道，确保场景切换时自动销毁。模块明确不接入标准 BossRush 共享 mutator roll，使用自身 reward catalog 与选项体系。
