- 所有运行时状态集中在 `ZombieModeRunState` 与 `ZombieModeOptionRuntimeState` 中，通过 `ResetForNewRun` / `ClearRuntime` 在 run 开始或结束时统一清零。
- 生命周期推进严格遵循 `ZombieModeLifecyclePhase` 与 `ZombieModeCombatPhase` 双状态机，任何阶段变更必须同步更新 `ZombieMode*Guard.py`。
- 运行时产生的 GameObject、协程、事件监听器通过 `RegisterZombieModeRunOnlyObject` 登记到 `ZombieModeRunState.RunOnlyObjects`，并在清理时调用 `CleanupAction` 释放。
- Boss 技能状态采用抽象基类 `ZombieModeBossSkillState` + per-kind 子类（Titan/Hunter/Splitter/Shielder/Corruptor），每帧由 `TickZombieModeBossController` 派发调用。
- 奖励系统按类型拆分到多个 `ZombieModeReward*` 文件，统一通过 `ZombieModeRewardType` 枚举 switch/case 分发选择与效果应用。
- 对游戏全局热路径（如 `Health.OnDead`/`OnHurt`）采用 early-return 守卫（先判断 `LifecyclePhase == None`），避免非丧尸模式下的 marker 查询开销。
