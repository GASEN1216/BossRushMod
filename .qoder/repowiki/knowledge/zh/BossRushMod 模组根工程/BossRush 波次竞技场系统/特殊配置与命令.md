波次竞技场运行时参数来自 `Config/Config.cs` 与 `ModConfigApi`，不要在 `WavesArena/` 内另建同义常量。常用配置包括：`waveIntervalSeconds`（波次间隔）、`useInteractBetweenWaves`（手动开启下一波）、`infiniteHellBossesPerWave`（无间炼狱每波 Boss 数）、`milestoneRestBonusSeconds`（里程碑额外休息）、`bossStatMultiplier`（Boss 全局倍率）、`enableRandomBossLoot`（随机掉落加成）、`disabledBosses`（禁用 Boss）和 `bossInfiniteHellFactors`（无间炼狱权重）。配置文件外部格式与 key 属于兼容契约，调整前需阅读 `docs/contracts.md`。

构建与验证命令：

```cmd
compile_official.bat
python tests\OfficialCompileListFileExistenceGuard.py
python tests\EnemySpawnCoreObservableGuard.py
```

修改波次、刷怪、敌对性或恢复逻辑后，还应运行对应 `WavesArena*Guard.py`、`EnemySpawnCore*Guard.py`，并在游戏内验证入场、开波、击杀结算、失败重试、下一波和退出清理。Mode G 复用共享生成核心，但其 `AllowRandomRetryFallback=false`、外部提交和 mutator 隔离是独立事务契约，不能用标准 BossRush 的宽松随机回退替代。
