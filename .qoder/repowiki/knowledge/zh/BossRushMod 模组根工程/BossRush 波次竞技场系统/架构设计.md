模块以 `ModBehaviour`（继承自 `Duckov.Modding.ModBehaviour`）为核心，通过分部类（partial class）按职责拆分为多个文件：
- `WavesArena.cs`：主状态机与波次控制，维护 `currentEnemyIndex`、`infiniteHellMode`、`bossesPerWave` 等状态，负责倒计时 (`StartNextWaveCountdown`)、敌人死亡回调 (`OnEnemyDiedWithDamageInfo` → `HandleBossDeath` → `ProceedAfterWaveFinished`)、Boss 池初始化与过滤 (`InitializeEnemyPresets`、`PruneNonBossEnemyPresetsFromCache`)、无间炼狱权重随机 (`PickRandomEnemyForInfiniteHell`)。
- `WavesArenaEntryAndTeleport.cs`：入口流程，`StartBossRush_WavesArena` 定位玩家并调用 `TeleportToBossRushAsync` 经 `SceneLoader.LoadScene` 加载竞技场场景，同时创建返回交互点。
- `BossRushEntryFlow.cs`：统一判定入场模式（Normal / Mode D / Mode E / Mode F / Mode G），优先级 E > F > D > Normal，在 DEMO 挑战场景加载后分支启动对应模式。
- `WavesArenaBossSpawning.cs`：生成逻辑，`SpawnNextEnemy` 根据模式选择预设，单/多 Boss 分别走 `SpawnBossWithVerificationAsync` / `SpawnMultipleBossesWithVerificationAsync`，含重试机制与安全刷怪点选择 (`FindNearestSafeSpawnPoint`、`FindMultipleSafeSpawnPoints`)。
- `WavesArenaSpawnerControl.cs`：运行时环境清理，`DisableAllSpawnerRoots` 反射设置 `CharacterSpawnerRoot.created=true` 并分帧销毁根节点，`TryFixStuckWaveIfNoBossAlive` 做波次完整性自检。
- `WavesArenaRuntimeHooks.cs`：每帧钩子 `TickWavesArenaRuntime` 驱动倒计时与波次完整性检查，`TickWavesArenaBossCleanupRuntime` 定期清理非 BossRush 召唤的“大兴兴”。
- `WavesArenaRuntimeModule.cs`：轻量运行时模块注册，仅持有 `ModBehaviour` 引用并通过 `BossRushRuntimeModuleBase` 生命周期管理。
依赖方向单向：入口/传送 → 生成 → 死亡回调 → 波次推进 → 下一波；所有外部游戏对象访问均通过 `ObjectCache`、`CharacterMainControl`、`SceneLoader`、`MultiSceneCore` 等框架接口，避免直接硬编码场景名。
