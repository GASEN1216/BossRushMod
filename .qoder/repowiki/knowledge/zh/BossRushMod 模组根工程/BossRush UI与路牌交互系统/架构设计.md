模块以 `partial class ModBehaviour` 的形式拆分到三个文件中，统一归属 `BossRush` 命名空间并继承自 `Duckov.Modding.ModBehaviour`：
- `UIAndSigns.cs`：核心实现层，负责消息提示 (`ShowMessage_UIAndSigns`)、大横幅通知 (`ShowBigBanner_UIAndSigns`，含动态内容去重与最小 2 秒时长保障)、路牌创建 (`TryCreateArenaDifficultyEntryPoint_UIAndSigns` / `CreateInvisibleEntryPointForChallengeSnow`)、垃圾桶生成 (`CreateTrashCanNextToSignpost`)、敌人生成横幅 (`ShowEnemyBanner_UIAndSigns`)，以及通过反射将 `BossRushInteractable` 注入到目标 `InteractableBase` 的 group 列表 (`InjectIntoInteractableBaseGroup_UIAndSigns`)。
- `BossRushInteractionScan.cs`：扫描层，协程 `FindInteractionTargets` 周期性遍历场景中所有 `InteractableBase`，按场景名（基地枢纽 vs BossRush 竞技场）定位目标并调用注入逻辑，注入成功后立即停止扫描。
- `UIAndSignsRuntimeBridges.cs`：薄桥接层，暴露无 `_UIAndSigns` 后缀的公开方法（如 `CreateRescueTeleportBubble`、`TryCreateArenaDifficultyEntryPoint`），由外部模块调用后转发到实际实现。
依赖方向单向：桥接 → 扫描 → 核心；核心通过 `EntityModelFactory` 创建模型、通过 `ReflectionCache`/`ObjectCache` 访问游戏内部字段（如 `NotificationText` 持续时间、`InteractableBase_OtherInterablesInGroup`），并通过 `L10n.T` 进行多语言文本处理。

## 2026-09-07 界面可读性与视觉整理（COMPAT）

共享层 `Common/UI/BossRushUI.cs` / `ZombieMode/ZombieModeUIHelper.cs` 现在统一以下表现约定：

- CanvasScaler 使用 1920×1080 参考尺寸与 Expand；`GetReferenceViewportSize()` 提供同口径逻辑视口，成就/图鉴的尺寸计算不再直接使用物理屏幕像素。
- 共享按钮标签在固定内边距内拉伸，青绿/纸面等亮底使用深字；`ApplyButtonColors` 在施加绝对 ColorBlock 前把 Graphic 复位成白色，消除两次相乘导致的过暗反馈。
- `SuccessText` / `WarningText` / `DangerText` 是深色面板上的状态文字，原 Success/Warning/Danger 继续作为承托文字的背景色。
- `MeasureTextHeight` 只用于低频创建的可增长内容：固定字号、测量换行高度，调用方必须把高度计入卡片与 ScrollRect。固定 HUD 仍保留限高/省略，不能随意开放 Overflow。
- `ConfigureScrollRect` 补齐空白区域滚轮命中、纵向拖动滑块及 Clamped 滚动；已存在的官方滑块继续复用。调用方为右侧滚动条预留 20px。
- Mode H 已有根遮罩时，`CreateModalSurface(..., createBackdrop: false)` 避免再叠一层；其它调用的默认行为不变。默认程序化皮肤保留实际圆角半径，图集注入仍优先。

`UILayoutReadabilityGuard` 检查容器边界、内容/动作避让、画布坐标与重复乘色，并含 6 个内存反向检查。它与 Windows 正式编译均不能代替 Unity 内的字体、滚动、悬停、分辨率与过图实测。

`Integration/Affinity/AffinityUIManager.cs` 的关系提示采用共享深色皮肤、320×104 留白和 20/16 号文字，原有心形图标保留；名称、等级、进度条分区，装饰与文字均透传点击。`Integration/UI/ImageViewerUI.cs` 的图片通过锚点和 preserveAspect 自动适配画布，上下各留 110px，避免 4K 二次放大；标题/提示绑定游戏字体。资源失败时明确提示“图片暂不可用”，不再创建大渐变占位图或无限显示“加载中”。`Integration/Codex/CodexView.cs` 的高度使用共享逻辑视口。原输入与资源归属流程保持不变；高清屏、长标题、加载失败与重开待实机复测。

**复核补修**：共享按钮的底色只有一个来源——`ColorBlock` 的绝对色，`Graphic` 恒为白；`CreateButton` 与 `ApplyButtonColors` 走同一路径，三态由 `BossRushUI.GetHoverColor / GetPressedColor / GetDisabledColor` 派生。**不要用大于 1 的中性乘色做悬停**（`CanvasRenderer` 的 tint 是 32 位色，>1 会被夹回白，悬停等于没做）；改已有按钮底色一律走 `ZombieModeUIHelper.SetButtonBaseColor`，直接写 `Image.color` 会与 ColorTint 相乘。亮底判定用 `BossRushUI.LightBackgroundLuminance`(0.30)，刻意远离 Warning/Success/Accent 三个 token。`Image.Type.Filled` 必须赋 `BossRushUI.GetSolidSprite()`，否则 `fillAmount` 被 Unity 完全忽略。遮罩分 `Backdrop`(0.62) 与全屏正片用的 `BackdropStrong`(0.90)。
