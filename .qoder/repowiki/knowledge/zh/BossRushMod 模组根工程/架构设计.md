根目录以 `ModBehaviour.cs`（partial class）作为 Unity 加载的唯一入口，在 Awake/Start/Update/LateUpdate/OnDestroy 中统一调用 `BossRushRuntimeModuleHost` 的生命周期钩子，将各子系统按职责拆分到独立目录并通过 partial 方法（如 `InitializeAchievementRuntime`、`StartIntegrationRuntime`、`TickModeRuntimeGroup`）注入。
- 运行时编排：所有 Harmony 补丁由 `Utilities` 中的 `AlwaysOnRuntimeHooks.cs` 集中 `PatchAll()`，场景门控由 `SceneRuntimeGate` 统一判定是否允许运行游戏逻辑。
- 模式分发：`ModBehaviour.Update` 内通过 `TickModeRuntimeGroup` 把当前帧调度给 WavesArena、ModeD/E/F/ZombieMode 等模式状态机，共享 BossRegen、现金磁铁、地图刷点等全局能力。
- 配置与数据源：`Config` 提供 JSON + ModConfig 双通道配置；`MapSpawnPointRegistry` 以 JSON 为唯一运行时地图刷新点来源，被多个模式复用。
- 内容接入：`Integration/` 作为统一注册层，把装备、物品、NPC、Boss、商店、Wiki、婚姻、死亡亡魂、星愿台等内容挂接到游戏系统，被各模式消费。
- 构建与验证：无 `.csproj`，由根级 `compile_official.bat` / `compile_dev.bat` 直接调用 Roslyn `csc.dll` 编译全部 C# 源码输出 `Build/BossRush.dll`；静态契约由 `tests/*.py` 守护，运行时冒烟由根级 `test_*.bat` 触发。
- 文档与站点：`wiki-site/`（VitePress）与 `WikiContent/` 分离，前者通过脚本从后者同步生成在线百科。
