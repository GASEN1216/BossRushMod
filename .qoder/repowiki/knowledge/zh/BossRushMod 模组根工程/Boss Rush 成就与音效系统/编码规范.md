- 通过 `partial class ModBehaviour` 将各子系统钩子（成就触发、音频 Hook）分散到独立文件中，统一挂载到游戏主行为类上。
- 成就定义采用集中 `Register(...)` 调用声明 id、中英文名称、描述、分类、现金奖励与难度等级，新增成就只需追加一行注册。
- 持久化数据统一通过 `SavesSystem.SaveGlobal/LoadGlobal` 配合固定 key（如 `BossRush_Achievements`、`BossRush_AchievementStats`）读写，并在异常时回退到空集合。
- 对第三方或可选依赖（如 `Duckov.AudioManager`、`EconomyManager`）一律使用 `Type.GetType` + `MethodInfo.Invoke` 反射调用，并用 try/catch 包裹以保证模组缺失时不崩溃。
- 关键路径与文件存在性结果通过静态字典缓存（如 `_cachedSoundFileExists`、NPC 交互 handler 表），避免重复 I/O 或反射开销。
- 所有公开入口方法均以 `try { ... } catch { DevLog/LogError(...) }` 包裹，并将 `[Achievement]` 或 `[BossRush]` 前缀日志输出到统一日志通道。
