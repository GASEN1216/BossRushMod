- 每个子系统拆分为 Config/Runtime/Bootstrap 三类文件，配置与行为解耦，由 Bootstrap 在启动时注册到对应 Factory 或 Registry
- 需要持久化或跨场景保持的状态通过 StaticCacheReset 文件在游戏重启时清空，避免脏数据累积
- Boss 与复杂 NPC 采用 AbilityController + AssetManager + Config 的组合模式，攻击、移动、特效分别拆分到独立文件
- 新增装备/物品统一通过 EquipmentFactory/ItemFactory 及 EquipmentContentRegistry/EquipmentHelper 注册，而非直接 new 实例
- NPC 相关子系统共用 Utils/NPC*Helper 与 Constants 下的常量，Movement/Dialogue/Interaction 等横切逻辑抽取为基类或工具
