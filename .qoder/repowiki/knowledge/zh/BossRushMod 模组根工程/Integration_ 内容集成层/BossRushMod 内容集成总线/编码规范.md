- 子系统通过 `*Bootstrap.cs` 暴露 `SetupXxxForScene(scene)` 方法，由 `IntegrationDeferredBootstrap` 在基础内容就绪后按场景句柄顺序调用。
- 长耗时初始化拆分为 `RunDeferredStep_Integration(label, () => ...)` 协程步骤，每步包裹 `SafeRuntime.Run` 并 `yield return null` 避免阻塞帧。
- 需要跨场景保持状态的系统提供 `*StaticCacheReset.cs` 供热重载时重置静态缓存。
- 持久化数据统一通过订阅 `Saves.SavesSystem.OnSetFile` / `OnCollectSaveData` 事件进行加载与保存，并使用 `BossRush_` 前缀的 save key。
- NPC 扩展通过实现 `INPCModule` 并由 `NPCModuleRegistry.AutoDiscoverModules` 反射发现，按 `SpawnOrder` 排序生成，禁止直接修改 `ModBehaviour.InitializeAffinitySystem`。
- 新增物品/装备一律经 `EquipmentFactory` / `ItemFactory` / `EquipmentContentRegistry` 注册，不得绕过工厂手写创建或注入。
