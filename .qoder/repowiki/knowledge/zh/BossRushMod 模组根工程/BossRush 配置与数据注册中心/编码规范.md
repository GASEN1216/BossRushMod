- 所有可配置项以 `BossRush_<Key>` 形式的字符串键声明，并在 `IsHandledModConfigOptionKey` 白名单中集中登记，新增配置需同步加入该白名单。
- 数值型配置在加载后统一通过 `Mathf.Clamp` 或显式 if 边界检查限制到预设范围（如波次间隔 2-60、倍率 0.1-10、每波数量 1-10）。
- 对可选外部依赖（`ModConfig` 模组）一律通过 `FindModConfigType` + `GetMethod` + `MakeGenericMethod` + `Invoke` 的反射调用链访问，失败时记录 `DevLog` 并优雅降级。
- NPC 刷新点按“场景名 → 配置对象”字典组织，新增场景只需向对应 `Dictionary<string, NPCSceneSpawnConfig>` 追加条目，无需修改核心查询逻辑。
- 黑名单与配置数据采用“外部 JSON + 硬编码兜底”双源策略：优先从 `JsonDataRegistry` 读取，解析失败或为空时回退到内嵌常量数组。
