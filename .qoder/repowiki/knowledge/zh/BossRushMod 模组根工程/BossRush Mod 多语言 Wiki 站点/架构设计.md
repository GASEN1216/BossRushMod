站点以 VitePress（docs/.vitepress/config.mts）为构建核心，通过 package.json 暴露 dev/build/preview/sync 四个 npm 脚本；内容采用「权威源 + 生成」模式：scripts/sync-content.mjs 读取仓库根目录 WikiContent/{zh,en}/catalog.tsv 及对应 Markdown 源文件，经标题层级提升、callout 转换、本地路径清理后输出到 docs/ 与 docs/en/，并自动生成英文首页 index.md。config.mts 中硬编码了 zh/en 两套 sidebar 与 nav，并通过 getChangelogItems 动态解析 catalog.tsv 中的 changelog 条目注入侧边栏，实现更新日志的集中维护。部署由 .github/workflows/deploy.yml 驱动，在 push main 分支时安装依赖、执行 npm run build，将 docs/.vitepress/dist 上传至 GitHub Pages；base 路径通过 DEPLOY_TARGET=cloudflare 环境变量切换为 / 或 /BossRushMod/。
