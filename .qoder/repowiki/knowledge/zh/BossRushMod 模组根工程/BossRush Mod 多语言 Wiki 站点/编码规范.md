- 所有页面内容以 Markdown 编写于 WikiContent/{zh,en}/ 下，通过 catalog.tsv 的 entryId 与 category 字段声明路由映射，再由 sync-content.mjs 统一转换生成 docs 树。
- WikiContent 源文件使用 ## 作为页面主标题、### 作为小节标题，并在同步阶段自动提升一级以适配 VitePress 的 #/##/### 层级。
- 提示性内容使用 [tip]、[warn] 行内 callout 语法，同步时转换为 VitePress 的 ::: tip / ::: warning 块级组件。
- 更新日志条目以 changelog__vX_Y_Z 形式的 entryId 命名，由 config.mts 与 sync-content.mjs 共同解析，按 catalog.tsv 中的 order 字段排序并生成 /changelog/vX.Y.Z 路由。
- 中英双语站点通过 docs/ 与 docs/en/ 平行目录组织，sidebar 与 nav 在 config.mts 中以独立的 sidebarZh/sidebarEn 函数分别定义，保持结构对称。
