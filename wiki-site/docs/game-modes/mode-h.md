# 百战留痕（黑市鸭王杯）

## 这是什么

你不下场，你押注。

每场两队 Boss 同时上擂台互殴：左边蓝队，右边红队，两队按战力配平，一场比一场人多。你挑一队押它赢，坐在看台上看它们打，全场只能拍一次铃，放一场两队都挨的天灾。一季固定六场，打完按押中的场数进名人堂排名。

## 怎么进

- 在**基地码头的那条船**上交互，选项里除了「Boss Rush」还会多出一条**黑市鸭王杯**。
- 花一张 **BossRush 船票**，和普通 BossRush 一样，在地图选择页点确认时才扣。
- **不需要任何模式专属道具**，也不用脱装备。
- 地图选择页会列出**能摆得下擂台的 BossRush 地图**，迷宫这种拐角多的图也能进：挑不出宽敞的场地时，会退一步接受绕一点的走位和隔着墙的看台。
- 有别的模式正在进行时进不来（标准竞技场、白手起家、划地为营、血猎追击、宿命回响、末日丧尸都算）。
- 万一开局被挡下来（内容没准备好、场地不合适、和别的模式撞上），**船票会退还给你**，并告诉你原因。

## 每一场怎么走

**赛前页（蓝队 vs 红队 + 押哪边 + 押注）→「开打」→ 看它们打（可以拍一次铃）→ 结算页 →「下一场」**

### 赛前页：两队一起摆出来

- 每场左右两队**一起抽**：左边**蓝队**，右边**红队**。卡上是图鉴立绘、名字和**战力**，列头写人数和合计战力。
- 两队合计战力**相差不超过 500**。
- **越打越大**：第 1 场一队大约 3~7 只，合计战力两千出头；之后逐场加码，第 6 场一队十几到 20 只，合计战力一万上下。
- 所有 BossRush 的 Boss 都可能被抽到，**同一只官方 Boss 可以重复出现**，运气好能看到一队 20 只全是同一只。三只模组 Boss（**龙裔遗族、幽灵女巫**战力 1000，**焚天龙皇**战力 2000）每队最多一只。
- 不满意点**「换一批」**，两队一起重抽，每场最多 **3 次**。页面原地换人，不会关掉再开。
- **押哪边赢**：「蓝队 xN」「红队 xN」二选一，后面的数字是押这一队赢的返还倍率。看好的那边通常倍率低，冷门那边倍率高。
- 页脚那排「押注」选好后点**「开打」**。

::: tip
旧版的「自己调整再开打」（战前换人、配装、选口令）已经去掉：群战没有整备这一步，你要做的决定只有「押哪队、押多少」。
:::

### 开打

- 两队同时上场，各自找最近的对手打。**一边全倒，另一边赢**；两边同时全倒算庄家赢，押哪边都算输。
- 血条名字后面带着**「- 蓝队」**（蓝字）或**「- 红队」**（红字）。
- 同一队的 Boss **不会误伤队友**：榴弹、火箭这类爆炸和模组 Boss 的范围技能只伤对面。拍铃的天灾例外，两队都挨。
- 单场最长 **240 秒**。到时还没分出胜负，按双方**还站着的人的战力 × 剩余血量**比大小。
- **切换观战对象**：开打时会提示按键。**A / ← / 鼠标左键**看上一个，**D / → / 鼠标右键**看下一个，**W / ↑** 跳到蓝队，**S / ↓** 跳到红队。镜头默认先跟你押的那一队；跟着的人倒了会自动换到同队下一个。
- 观战界面右侧有**投降**和**退出**：投降按这一场押输结算；退出会离场，这一场留着以后重打，押注按输结清。

## 拍铃：一场全场天灾

整场比赛，你只有一个主动操作：**拍铃**。

- 每场只能拍一次，拍下去随机来一场天灾，**两边一视同仁**：
  - **陨星雨** — 8 秒里陨石乱砸，砸中谁算谁；
  - **导弹轰炸** — 三轮导弹随机点名，敌我不分；
  - **全员加速** — 15 秒内所有人移速 +50%；
  - **全员狂暴** — 15 秒内所有人伤害 +50%；
  - **回春** — 场上所有人立刻回 30% 血；
  - **寒潮** — 12 秒内所有人移速 -40%。
- 陨石和导弹按每人最大生命的比例扣血，血厚血薄挨一下的分量一样。
- 拍铃不暂停战斗，卡片上写着这次来的是什么，底边细线是剩余时间。

::: tip
天灾不偏向任何一边。你押的那队人多血少时，陨石导弹可能帮倒忙；人少但个个硬时，乱砸反而是机会。
:::

## 结算与一季

- 结算页写明**哪队赢了、你押了哪队、两队各还剩几个人、耗时、这场来的天灾**，以及押注结果。押中就是「本场胜利」。
- 一季**固定六场**，输了也接着打，不会中途结束。第 6 场的结算页之后进名人堂。

## 押注：押你选的那一队赢

::: warning
押注押的是你的钱或背包里的东西：押你选的那一队赢，输了押上的归庄家。长期来看，庄家总是赢的。
:::

能押两样：**账户里的钱**（背包里的现金不会动），或者**背包里的物品**。**仓库里的东西一件都不押**：比赛在出击地图上打，仓库只在基地，押不了。

- **在哪选**：赛前页、每场的结算页（管下一场），页脚都有一排「押注」：**不押 / 押 1,000 / 押 5,000 / 押 20,000 / 押物品**。
- **押钱选的是「接下来每场押多少」**：选一次，之后每场都按这一档押，直到你再改。默认不押，读档之后也回到不押。
- **押物品只管下一场**：点「押物品」打开一页背包物品，点一件押上、再点取下，选好点「完成」回原来那页。
- 开打锁盘成功之后才扣押金、记下押上的东西；钱不够、东西已经不在背包里，这一场就不押，结算页写明原因，比赛照打。

### 押物品

- **能押什么**：背包里的东西随便押，押几件、押多贵都不限。只有任务物品和不值钱的东西不会列出来。装着东西的容器也能押，输了连里面的一起收走。
- **估值**：按商人收购价算，也就是原价的一半。押东西不会比直接卖掉划算。
- **押上的东西不会先被拿走**，比赛期间一直在你背包里。**输了**押上的东西被收走。
- **赢了**东西留着，另得**奖品**：品质跟押上的东西走，总价值等于「赢了拿回多少」减去估值，押几件发几件（最多 6 件）。背包满了会保留待领奖品，腾出空位后自动补发。
- 开打后别去挪押上的东西：输了时找不到的部分按估值从余额里扣，扣到 0 为止。

### 赢了拿回多少

赢了拿回 = 押金 × 0.92 ÷ 这一档的假定胜率。拿回的钱**含押金**：

- **x1** — 假定胜率 85%，大约拿回 1.08 倍
- **x2** — 假定胜率 70%，大约拿回 1.31 倍
- **x3** — 假定胜率 55%，大约拿回 1.67 倍
- **x4** — 假定胜率 42%，大约拿回 2.19 倍
- **x5** — 假定胜率 30%，大约拿回 3.06 倍

比如押 5,000、x3 赢了，拿回 8,360。某一档**实际**打出来的胜率（这一档押满 20 场之后）比表里高时，这一档的赔付会自动往下调。

### 中断与退回

- **押注跟着这一场走**：技术中止、赛季挂起、中途退出游戏再回来，这一场都要重打（会重新抽人）。押注**不退**，重打时沿用，按重打的结果结算。
- 只有这一季不再打了才原样退回：恢复页里「放弃本赛季」，或者开新一季时发现上一季还挂着押注。

::: warning
押之前先问自己一句：这笔钱没了，我还想不想接着玩。不押一样能打完整季。
:::

## 名人堂：排名榜

打完第 6 场，这一季会记进**名人堂**，按战绩排名：

- 先比**押中了几场**，一样多比**押注净赚**，再一样就先入堂的在前。
- 每条是一张卡：名次、押中几场、净赚多少，配一张**头号功臣**（这一季你押的那队里出场、押中最多的那只 Boss）的立绘。本季那一行会高亮，页头写「本季排第几名」。
- 名人堂**跨赛季保存**，只有 **32 席**。满了之后**排名最末的那一季被挤掉**。
- 旧版单挑时代的冠军记录排在排行榜后面，写着「往届单挑冠军」。
- 看完点**「结束赛季」**，这一季就收尾了。

## 几个你可能会问的问题

- **每次进来都要等热身吗？** 不用。地图加载完成后直接进选人页。
- **看不到自己的角色正常吗？** 正常。开打后镜头跟着场上的 Boss（按键可以切换），你的身体安静地待在看台上，比赛结束镜头会回到你身上。
- **我能自己下场打吗？** 不能。你只押注和拍铃。
- **能带遗种巢的崽子吗？** 不能。本模式不接入遗种巢随从。
- **会有变异词条吗？** 不会。百战留痕不吃变异词条，局内也不触发随机事件。
- **这里的击杀算进鸭皇图鉴吗？** 不算。场上是 Boss 在互殴，不是你亲手打的。
- **中途出了技术故障会判我输吗？** 不会。会按同一场自动重试，最多 2 次，不算败场；押了注的话押注不退，重打时沿用。继续失败时暂停赛季，由船点恢复页处理。
- **赛季卡住了，进不去也打不下去怎么办？** 去码头交互，出来的会是一张恢复页。点**「放弃本赛季并结清押品」**会先弹一个确认框写清后果；确认之后挂着的押注原样退回，清掉卡住的赛季，你就能重新开一季。暂时不想处理，点**「稍后处理」**关掉。

::: tip
这个模式真正要你做的只有三件事：押哪队、押多少、那一次铃什么时候拍。剩下的交给它们了。
:::
