# 鸭科夫日报

## 这是什么

《鸭科夫日报》是一份会自动送到你基地的报纸，每个游戏日出一期，把你昨天干的事写成新闻。

它把已有玩法串成一条回基地后的短流程：看看战报、挑一条顺路能做的悬赏、签个到，再去快递站取奖。悬赏自动计数，不用接任务；不想做也不会影响出击。

报纸里的运势和杂谈只是趣味文字，没有隐藏属性加成或需要寻找的秘密任务。

## 如何开始订阅

- 在基地的建造界面里造一个 `报箱`，造价 `500` 金，**只能建一个**，位置随你摆。
- 造好后靠近它，会看到交互选项 `阅读今日报纸`。
- 打开后就是完整的报纸面板。

## 一天有多长

- 一个游戏日约等于 `24` 分钟现实时间（游戏内时钟是现实时间的 60 倍速）。
- **只要游戏在跑就算**：你在基地挂机也照样推进，暂停和停留在主菜单时不计时。
- 睡觉和"继续游戏"造成的时间跳跃**不会**让你白跳一期——日报按实际游玩时长自己算天数。
- 退出游戏不会算作断签：计时器只在你实际游玩时前进。
- 报纸顶部显示当日进度，以及按当前时钟倍率估算的剩余游玩分钟。暂停和离线不会消耗这段时间。

## 报纸上有什么

- **头版头条**：根据你昨天的表现自动选题。砍了首领、屠了几十个杂兵、连着阵亡好几次、
  或者大赚一笔，都会有对应的稿子。什么都没发生也有专门的稿子。
- **昨日战绩**：击杀数、首领数、出击与撤离次数、阵亡次数、收支、输出、承伤和最大单次伤害。击杀只计玩家击杀的敌方角色，首领包含在总击杀里；承伤包含环境伤害。
  百战留痕的比赛不进这一栏——那是你的选手在打，不是你的战绩，悬赏进度同理不推进。
- **悬赏栏**：公布昨天的悬赏结果，同时给出今天的新悬赏、实时进度、奖金与结算时间。
- **气象与杂谈**：世界时间明日此时的天气预报（含风暴预警，不代表一整天；地图固定天气时单独标注）、今日运势的宜与忌、坊间传闻。
- **签到墙**：一整期 30 格。

## 每日悬赏

每天一条，从五类里随机抽一条，还会随机抽一个难度档（轻松 / 常规 / 硬核），
目标和奖金一起变：

- **清剿敌人** — `30 / 60 / 120` 名，奖金 `800 / 1,600 / 3,200`
- **讨伐首领** — `1 / 3 / 5` 只，奖金 `1,200 / 3,000 / 5,000`
- **成功撤离** — `1 / 2 / 4` 次，奖金 `700 / 1,400 / 2,800`
- **单日进账** — `5,000 / 15,000 / 40,000`，奖金 `900 / 2,000 / 4,500`
- **成功撤离且当日零阵亡** — 固定奖金 `1,500`

几条规则：

- 同一天无论重开几次游戏，悬赏都是同一条，**不会刷新**。想换只能等明天。
- 报纸显示实时进度与状态。「目标已达成」会等下期结算；零阵亡悬赏若当天已经阵亡，会明确显示「今日已失败」，不必再为这条悬赏反复出击。
- 达成后会在**次日的报纸上公布**，奖金自动发放。
- 「零阵亡」需要当天**至少成功撤离一次**，而且直到下次出刊前都没有阵亡。只出门未回来不算；跨天的出击按实际撤离日计数。
- 「单日进账」只看收入，不扣支出；日报自己的奖金不会推进悬赏。
- 现金暂时无法发放时会显示待补发；旧欠款会保留，后续每天仍照常结算。再次打开日报会重试，成功后显示已到账。

::: tip
早上先翻一眼报纸，把今天的悬赏和你本来就想打的模式对上：抽到「讨伐首领 5 只」就去打标准竞技场，抽到「成功撤离 4 次」就打短局。顺路赚的钱才是白赚的。
:::

## 签到与奖励

每天打开报纸点一次 `签到`，一天只能签一次。一期 30 格。

**每天都送 1 件品质 `2` 的随机小礼**，寄到快递站；抵达下面的里程碑时，再额外送对应品质的奖品。普通小礼和里程碑都会保留未送达的欠奖。

更新后，如果当天已经签过但尚未领每日小礼，再次打开报纸会补发一次。过去没有记录的普通签到日不追溯补发。

**第 1 期**是入门期，奖励逐级往上走：

- 第 `7` 格 → 品质 `5` 随机奖品
- 第 `15` 格 → 品质 `6`
- 第 `24` 格 → 品质 `7`
- 第 `30` 格 → 品质 `8`

**第 2 期开始**换成稳定发放：格子编号从 31 数到 60，每一期的第 `7 / 14 / 21 / 28` 格
各发一件，**品质固定为 `8`**。也就是说签到进入第 2 期后，每累计 7 次连续签到就逐步抵达新的奖励格；这里的“天”都是游戏日。

- 里程碑格在签到墙上是金色的，带 `★` 标记，隔多远都看得见。
- **断签会清空本期进度**：某一天没签，跨天时本期格子清回 0 重新开始。
  但**已经翻过的期数不会退回去**——你不会从第 2 期掉回第 1 期，也就是说奖品品质不会倒退。

::: warning
漏签会重置本期签到进度，期号和已挣得的奖品保留。离线、暂停不会推进日报日；不需要按现实日期上线打卡。
:::

## 奖品去哪了

- 奖品默认寄到**快递站的待领取列表**里，不会直接塞进你的背包。
  屏幕上会弹一条「签到奖励已寄往快递站」的提示。
- 因此你在打副本的途中跨天也没关系，东西丢不了，回基地慢慢取。
- **万一快递站收不下**（比如缓冲满了），系统会退而求其次直接把奖品塞给你——
  进背包、进仓库，或者掉在你脚下。这种情况下它**不会**再往快递站补一份，
  所以别看到快递站没东西就以为丢了，先翻翻背包和脚底。
- 真的两条路都失败了才算发放失败，下次打开报纸时会自动补发；断签、翻期也不会抹掉已经挣得的奖品。
- 对应品质暂时没有可用物品时保留待补发状态，不会悄悄换成低品质奖品。
- 正文和签到墙可以滚动阅读，关闭按钮固定在下沿。签到区会显示下一档奖品的品质，欠发时显示待补发数量。

## 需要开启吗

- 不需要。日报随 Mod 默认启用，没有任何开关要拨。
- 真正决定你读不读报纸的是那个报箱：不造它就没有阅读入口，天数照常在走，
  你随时改主意造一个都来得及。
