# 鸭皇图鉴

## 这是什么

一本会自己记账的 Boss 收集册。你每亲手宰掉一个 Boss，图鉴里对应的格子就从黑剪影变成彩色立绘。

它不改变任何战斗规则，它改变的是你**为什么**去打某一只 Boss——为了那个还没亮起来的格子。

## 怎么打开

- 在基地商店买一本 `鸭皇图鉴`，售价 **4000**，**全店只有 1 本**。
- 买到后在背包里对它使用（右键）即可打开面板。**使用不消耗**，买一次就够，这辈子都不用再买。
- 这本书就是唯一的入口。图鉴面板不占快捷键，也不在别的界面里另开一扇门——想翻就翻背包。

**没买书也在记。** 这本书是「看」的工具，不是「记」的开关——你从装上 Mod 那一刻起打死的每个 Boss
都已经记在账上了。等你哪天想起来买书，翻开就能看到一堆已经点亮的格子。所以不必为了收集而
特意先去买书，也不会因为买晚了少算什么。

::: tip
4000 块买一本永久收藏册，是这个 Mod 里性价比最高的一次消费——光第一个条目的里程碑奖金就是 5 万。
:::

## 面板上有什么

- 顶部是收集进度条，标着里程碑刻度，一眼看出离下一笔奖金还差几只。
- 下面是 **4 列**的卡片网格，每张卡上有：立绘、名字、累计击杀数、最快击杀、初见日期。
- 点任意一张卡片可以放大立绘看细节。未解锁的是压黑的剪影，轮廓还在，内容全黑。

## 记录些什么

每个条目会记四样东西：

- **累计击杀数** — 你一共宰了它多少次。
- **初见日期** — 第一次打死它是哪天。
- **首杀模式** — 那一次发生在哪个模式里（标准竞技场 / 无间炼狱 / 白手起家 / 划地为营 /
  血猎追击 / 宿命回响 / 末日丧尸 / 原版撤离图）。
- **最快击杀** — 从你第一次打到它开始计时，到它倒下为止。中途躲起来磨时间会拉长这个数字。

## 哪些 Boss 会进图鉴

- 原版 Boss 池里的全部 Boss。
- 本 Mod 的三个自定义 Boss：龙裔遗族、焚天龙皇、幽灵女巫。
- 末日丧尸模式的五个 Boss（巨坦、极速追猎、分裂尸群、护盾统御、腐蚀地面）也各占一格。

**几乎所有模式都算数**：标准 BossRush、无间炼狱、白手起家、划地为营、血猎追击、宿命回响、
末日丧尸，甚至你在原版撤离图里顺手打死的 Boss 都会记进来。

**唯一的例外是百战留痕**：那个模式里你不下场，Boss 是你签的选手打死的，不算你亲手击杀，
所以不进图鉴，也不刷新最快击杀。

## 里程碑奖励

解锁到一定数量会自动解锁成就并发奖金，走的是你已经熟悉的成就系统：

- 解锁第 **1** 个条目 → `$50,000`
- 解锁 **10** 个 → `$150,000`
- 解锁 **20** 个 → `$400,000`
- **全收集** → `$1,000,000`
- 另有一个趣味成就「十秒之内」：任意 Boss 在 **10 秒**内解决掉 → `$200,000`

五个加起来是 **180 万**。对一本 4000 块的书来说，这买卖不亏。

::: tip
「十秒之内」建议拿血最薄的小 Boss 刷。计时从你第一次打到它开始算，所以先把爆发技能和满弹匣准备好，接触的第一下就要打出全部输出。
:::

## 几个你可能会问的问题

- **别人帮我打死的算吗？** 不算。只记你亲手造成致命伤的击杀，随从、宠物、雇佣兵和环境伤害都不算。
- **遗种巢的崽子打死的算吗？** 不算，随从被专门排除了。想收集就自己动手。
- **同一只 Boss 反复打有意义吗？** 有。累计击杀数会一直涨，最快击杀也可能被刷新，
  但格子只需要点亮一次。
- **换存档会怎样？** 图鉴跟着**存档槽位**走，每个档单独收集。这样里程碑奖金才不会出现新档白拿的情况。
- **我在 Boss 筛选器里禁用了某个 Boss，之前的记录会没吗？** 不会。
  已经收集过的条目会一直留在图鉴里，显示名用你当初记录下来的那个——
  图鉴管的是「你打过什么」，不是「现在还能不能打到」。
- **全收集要收多少个？** 取决于你当前的 Boss 池。官方 Boss 数量会随游戏版本变，
  面板顶部的进度条上写的分母就是当前的答案。
- **买书之前打死的算吗？** 算。记录一直在跑，书只是用来看的。

## 需要开启吗

不需要。图鉴随 Mod 默认启用，装上就在记账，没有任何开关要拨。
