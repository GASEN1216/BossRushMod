# 变异词条系统

## 这是啥？

每局开始前，系统会从 28 条词条池里随机抽几条出来，立刻生效并贯穿整局。**抽几条是固定的**，由设置里的 `mutatorCount` 决定，默认 **3 条**（可调 1~10）；随机的是抽到哪几条。词条可能给敌人增益、给玩家增益，也可能改变环境规则。

> **末日丧尸模式例外**：丧尸模式有自己独立的局内奖励增益系统，不走这套机制。

## 适用模式

| 模式 | 是否抽词条 |
|------|---------|
| 标准 BossRush | ✅ |
| 无间炼狱 | ✅ |
| 白手起家 | ✅ |
| 划地为营 | ✅ |
| 血猎追击 | ✅ |
| 宿命回响 | ❌（九波反制编排固定，不容额外变量） |
| 百战留痕 | ❌（看盘写什么，场上就是什么） |
| 末日丧尸模式 | ❌（独立系统） |

## 如何查看当前词条？

- 开局后，屏幕**左侧边缘**会出现“本局变异”列表，并显示本局词条总数
- 每一行都标明它属于**敌方 / 增益 / 规则**哪一类，颜色也会随类别区分
- 鼠标悬停某一行时，右侧会展开全部词条的完整说明，并高亮你正在看的那一条
- 词条较多、详情放不下时可以在展开区域滚动；鼠标从列表移到详情区时不会突然消失

## 配置

- **开关**：`enableMutators`（默认 `true`）
- **数量**：`mutatorCount`，范围 1~10，默认 **3** 个/局
- 可通过 ModConfig UI 或配置文件修改

## 常见问题

**Q: 好词条和坏词条概率一样？**  
随机从池里抽取，不区分对玩家有利与否。同一局可能同时抽到「巨灵兵」和「玻璃大炮」。

**Q: 能不能只抽玩家增益词条？**  
不行，词条是无差别抽取的，不能指定类别。

**Q: 词条会在局结束后清除吗？**  
会，所有词条在任意形式的局结束（通关/死亡/主动撤离）后自动清除，不会污染下一局。

**Q: 天降殉爆真的会伤到我？**  
会。敌人死亡时触发的爆炸会对玩家造成伤害，建议保持距离击杀，避免被连环引爆。有内置防递归保护，不会造成无限连锁。
