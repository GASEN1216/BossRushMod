# 模式专属物品

# 划地为营专属

# 战术消耗品——搞事用的

只能在划地为营里用，神秘商人的"其他"商店有卖：

- **挑衅烟雾弹**（蓝色）— 在最近 10 个刷怪点生成随机阵营 Boss。**主动找事用的**
- **混沌引爆器**（紫色）— 全图所有刷怪点生成随机阵营 Boss。**全图炸锅**
- **猎王响哨**（蓝色）— 50 米内所有敌对 Boss 强制追你。**我全都要**
- **血狩烽火**（紫色）— 全图所有敌对 Boss 强制追你。**勇者才用**

每击杀 10 个 Boss，系统自动送 1 个挑衅烟雾弹——打得越多送得越多。

挑衅烟雾弹和混沌引爆器不再受场上 Boss 数量上限限制。前者始终尝试最近 10 个刷怪点，后者尝试全图所有刷怪点；上一轮呼叫完成前不能再次使用。

营旗详见入场与功能物品。

# 血猎追击专属

# 工事道具——修碉堡用的

血猎追击限定道具，击杀 Boss 获取，神秘商人也有卖：

- **折叠掩体包**（绿色，堆叠 10）— 部署轻型掩体（250 血），最基础的防御工事
- **阻滞铁丝网包**（蓝色，堆叠 5）— 部署带刺铁丝网（200 血），没有碰撞体积但**大幅减速敌人**
- **加固路障包**（紫色，堆叠 5）— 部署重型掩体（500 血），**硬得一批**
- **应急维修喷剂**（绿色，堆叠 10）— 修复 3 米内受损的己方工事，回复 25% 最大血量

# 怎么部署？

- 使用后进入部署预览：**左键确认 / 右键取消 / 滚轮旋转 / 中键 90 度旋转**
- 维修喷剂会高亮 3 米内最近的受损工事，左键确认维修
- 部署在鼠标指向的位置
- 不能太近、不能重叠、不能被场景挡住
- 部署失败？物品退还，不亏

# 打 Boss 自动获取

- 每次击杀 → 1 个折叠掩体包
- 每 3 次击杀 → 1 个维修喷剂
- 每 10 次击杀 → 1 个加固路障包
- 每 20 次击杀 → 1 个铁丝网包

开局自动送 1 个折叠掩体包。

血猎收发器详见入场与功能物品。

# 宿命回响专属

# 宿命回响信物

宿命回响的入场信物，详见入场与功能物品。它会在确认进入时消耗，只有第 9 波胜利才返还。

- 携带自己的装备、BossRush 船票和信物进入
- 进入地图后从两项宿命契约中选择一项
- 失败不返还本局消耗的信物

# 末日丧尸模式专属

# 便携安全区装置

**便携安全区装置**（紫色，堆叠 1）— 丧尸模式的波次奖励之一，一次性使用，仅在丧尸模式局内生效。

- **战斗中使用** — 把安全区搬到你当前位置；波次结束后随准备期清理消失，重新生成带商人的正常安全区
- **准备阶段使用** — 额外部署一个不带商人终端的安全区，与正常安全区并存到下一波开始
- 部署完成时立即清走区内的普通/特殊/精英丧尸（不计击杀、不掉落、不给净化点），Boss 只会被推到排斥边界外
- 在安全区内用枪械或近战直接伤害丧尸会立即取消整个安全区——投掷物和奖励弹道不会误触发

安全区规则详见末日丧尸模式页面。
