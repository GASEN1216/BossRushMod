# 星阙

冠军之影的专属近战光棍。击败鸭王征程第六章冠军后获得，不进入随机奖池。

沙卫也会使用星阙光棍，但击杀沙卫不会掉落任何物品。

光棍与招式全部由程序光效组成：香槟金细芯、双螺光纹与淡青残影，挥动时棍端拖出残光，蓄势时断环向棍身收束。每次命中有星芒、冲击环、斩痕与火花，并配专属打击音效；击杀时星点散开并多停一拍。三档重击层次逐档递进：横扫是金色主刃、残影刃与沿弧甩出的流星光痕；回旋两段金、青交替，各带一条绕身上旋的星屑龙身；星陨有流星坠落、两拍光柱、贴地四射的星屑与余震环。停顿与震屏跟随真实命中，空挥与无敌目标不会触发。

重击可以打破冠军的沙泡与沙鲨；这些弹体不提供棍势。

# 棍势与操作

- 左键轻击，每两次有效命中攒一豆，三段连招的第三下命中算两次，最多三豆。同一挥击打中多个目标只算一次。
- 按住右键蓄势，每 0.45 秒长一豆。松开右键消耗现有棍势出重击；没有星豆或体力不足时头顶会提示，星豆不会丢。
- 一豆「流星横扫」：前方大范围金色光弧，命中击退，适合迅速清出身前空间。
- 二豆「双龙回旋」：金、青两道回旋先后命中，第二段把敌人卷近。
- 三豆「星陨天崩」：前冲后砸落巨型光棍，沿直线与落点冲击圈结算一次重击。
- 换下武器、死亡或切图会清空棍势并取消蓄势。

# 属性与来源

- 品质 6，基础伤害 42，攻击速度 1.45，轻击范围 2.3。
- 耐久 100，支持维修与重铸，基础价值 78000。
- 轻击每下消耗体力 5；重击一豆 4、二豆 7、三豆 11，体力不足不能释放。
- 接下第六章任务后进入竞技场，在没有其他模式进行时与报名石交互，挑战冠军之影。

::: tip
一豆起手快，二豆适合被围，三豆需要预判落点与收招空隙。蓄满三豆并不总是最好的选择。
:::
