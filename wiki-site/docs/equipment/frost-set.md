# 霜冠套装

::: tip
已正式开放获取：「???」Boss 身上掉，原版地图和 BossRush 场次都算；也可以在叮当的小店好感 6 级限量购买。叮当的说法也改成了「上头批出库了」。
:::

## 这是啥？

**冰霜系双件套**，由头盔「霜冠」与护甲「寒冰铠甲」组成。单件只有基础护甲与寒冷防护；同时装备两件激活「**寒冰之护**」：冰伤转治疗、普攻附带霜噬、受击冻结攻击者，外加淡蓝双眼呼吸光与脚下霜雾。它主打元素防护和反制，清场输出低于龙裔和龙王套装。

## 套装组合

- **霜冠**（头盔）：品质 6，头甲 +5，寒冷防护 +1，物品 ID 500053
- **寒冰铠甲**（护甲）：品质 6，体甲 +5，寒冷防护 +1，物品 ID 500054
- 耐久度：100
- **死亡掉落**：和龙王套装一样，死亡时会随身上装备一起掉出去（没有绑定标签），带着它出击就得做好丢的准备
- **维修**：可在维修台修复，出击前留意耐久

## 获取途径

- **「???」Boss 掉落**：击杀「???」时独立判定一次：霜冠 20%、寒冰铠甲 20%、60% 空。它另有 50% 额外掉霜之哀伤，两次判定互不影响。**原版地图正常出击也算**，不必进 BossRush；在竞技场里它会进 Mod 奖励箱，在无间炼狱里直接掉在地上。
- **叮当的小店**：好感 6 级上架两件，各限量 1（每次开店重置），单件 30000。
- 不进任何随机奖池（许愿台、日报签到、普通 Boss 随机箱都抽不到），只有这两条路。

## 2 件套效果：寒冰之护

同时装备霜冠 + 寒冰铠甲时激活，屏幕上方会出现提示，双眼亮起淡蓝呼吸光，脚下环绕一圈霜雾。

**被动：**
- 冰属性伤害减免 **+50%**
- 受到的冰系伤害再按 **50%** 回补为治疗（下一帧生效，绿色数字）
- 寒冷防护 +2（两件合计）

**霜噬（普攻附带）：**
- 普通攻击命中敌人时，为这一击追加 **5 点冰伤**，并有 **35%** 概率**冻结**被打中的目标
- 每 **1.1 秒**最多触发一次（内置冷却，与射速无关）
- 追加伤害是固定值，不随武器伤害缩放；高射速武器不会因此变强
- 只认武器 / 手雷的直接命中（持续伤害与套装自身的伤害不触发）

**冻结反击（受击触发）：**
- 被距离 **5 米以内**的攻击者命中时，有 **30%** 概率**冻结**该攻击者
- 每 **5 秒**最多触发一次
- 背面受击同样可触发，但攻击者仍须在 5 米内
- 冻结优先用套装自带的冰冻效果；资源缺失时回退原版寒冷，再不行走临时减速

## 实战体验

- 霜噬是持续控制：每 1.1 秒最多冻一次，稳定但不会因为换高射速武器而变强；利用冻结窗口拉开距离
- 冰伤回补对使用冰冻攻击的特殊丧尸与冰系 Boss 特别有效
- 30% 反冻概率在近战缠斗中频繁触发，5 秒冷却比大多数反击类装备宽裕
- 基础护甲（头甲 +5 / 体甲 +5）偏低，不适合纯坦克流；它靠控制活

::: tip
反冻最适合对付一直追着你打的近战型 Boss（如猎手、龙皇）。冻住之后有足够时间输出或拉开距离。
:::
