# 星工装备

::: tip
残星匠首每趟穿全套星工装备，倒下必定按 35% / 35% / 30% 留下头盔、护甲或背包之一；瞭台观星手另有 30% 概率留下观星镜盔。专属装备占尸体箱一格，其余是原有物资。
:::

## 这是啥？

**残星工坊的岛主「残星匠首」与残星瞭台的头目「瞭台观星手」身上穿的装备**：星铜护目盔、星炉背甲、星炉背囊出自匠首，观星镜盔出自观星手。穿上就有官方头甲 / 体甲 / 背包容量；在群岛上还各有用处 —— 星工装备任意两件让浮舟的渡口工台少收一片残铜片，观星镜盔戴着站定就能替你盯出附近的敌人。

## 四件装备

- **星铜护目盔**（头盔）：品质 5，头甲 +3，耐久 70，物品 ID 500086
- **星炉背甲**（护甲）：品质 5，体甲 +3，耐久 100，物品 ID 500087
- **星炉背囊**（背包）：品质 5，背包容量 +6，物品 ID 500088
- **观星镜盔**（头盔）：品质 5，头甲 +2，耐久 50，物品 ID 500089
- **维修**：有耐久的三件可在维修台修复（背囊没有耐久）
- **死亡掉落**：没有绑定标签，出击中倒下会和身上其他装备一起留在原地

## 获取途径

- **残星匠首**（岛主，残星工坊航标守卫）：每趟出击都在。倒下**必掉一件**：星铜护目盔 35%、星炉背甲 35%、星炉背囊 30% —— 多打几趟才凑得齐。
- **瞭台观星手**（头目，残星瞭台守卫）：倒下 **30%** 掉观星镜盔，70% 不掉。
- 掉出来的那件**耐久是满的**；它身上没抽中的几件不会进箱子。
- 不进任何随机奖池（岛上物资池、许愿台、日报签到、Boss 随机箱都抽不到），只有这两位身上这一条路。

## 在群岛上的用处

**星工两件套**（星铜护目盔 / 星炉背甲 / 星炉背囊任意两件同时穿着）：
- 在浮舟的渡口工台做**要两片以上残铜片**的配方时，少收 **1 片**；合成面板上的材料数会按你身上穿着的件数直接显示。
- 只看合成那一刻穿着几件，脱下就恢复原价。

**观星镜盔**（戴着且耐久没打光）：
- 在岛上**站定 2 秒**，40 米内活着的敌人脚下亮起一圈星标，持续 4 秒；之后冷却 8 秒。
- 耐久被打光就不再起作用，修好即可。

## 打法提示

**残星匠首：**
- 血量降到 **70% / 40% / 15%** 时各立起 **2 根星炉供能桩**（离它 5.5–8.5 米）：桩在的时候它头甲、体甲各厚 6 点。先拆桩；桩 25 秒后也会自己熄。
- **星焰落点**：在你周围落 3 个预警圈，约 1.25 秒后炸开（半径 2.6 米）—— 看到圈就横移出去。
- 每放两轮星焰会**过热 4 秒**：停手，受到的物理伤害加深 25%，这是输出窗口。
- **打坏装备会断招**：护目盔耐久打光后星焰只落 1 个圈；背甲耐久打光后桩给的加甲减半。

**瞭台观星手：**
- 在 8–42 米内、看得见你时，先在你脚下亮一圈标记，跟着你约 0.8 秒后锁定，再过 0.6 秒在锁定处落**两发星火**（半径 2.2 米，间隔 0.4 秒）。
- 锁定后离开圈子；或在它瞄准时躲到掩体后面断开视线 —— 标记会取消，但它会更快重新瞄准。
- 贴到 **8 米内**它就只能普通射击。
- 打光它镜盔的耐久，它就再也标不了人。

::: tip
两位都有 Boss 血条和名字。匠首与观星手的首杀会记进群岛手记的「岛上的事 → 这一趟 · 旅程进度」。
:::
