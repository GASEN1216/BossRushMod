# 雷神套装

::: tip
已正式开放获取：风暴区 Boss（四骑士、口口口口等）身上掉，原版地图和 BossRush 场次都算；也可以在叮当的小店好感 6 级限量购买。叮当的口径也改了——「上头批出库了」。
:::

## 这是啥？

**雷系双件套**，由头盔「雷神之角」与护甲「雷霆战甲」组成。单件只有基础护甲与风暴防护；同时装备两件激活「**雷霆之怒**」——电伤转治疗、击杀引雷连锁、受击雷霆反震，配青白色双眼电闪与周身电弧，是与龙王套装同级的毕业装。

## 套装组合

- **雷神之角**（头盔）：品质 6，头甲 +5，风暴防护 +1，物品 ID 500055
- **雷霆战甲**（护甲）：品质 6，体甲 +5，风暴防护 +1，物品 ID 500056
- 耐久度：999（近似永久）
- **死亡掉落**：不会因死亡掉落

## 获取途径

- **风暴区 Boss 掉落**：击杀四骑士、口口口口这类风暴区 Boss 时独立判定一次：雷神之角 20%、雷霆战甲 20%、60% 空。**原版地图正常出击也算**，不必进 BossRush；在竞技场里它会进 Mod 奖励箱，在无间炼狱里直接掉在地上。
- **叮当的小店**：好感 6 级上架两件，各限量 1（每次开店重置），单件 30000。
- 不进任何随机奖池（许愿台、日报签到、普通 Boss 随机箱都抽不到），只有这两条路。

## 2 件套效果：雷霆之怒

同时装备雷神之角 + 雷霆战甲时激活，屏幕上方会出现提示，双眼亮起青白电光，肩上每隔几秒闪一道小电弧。

**被动：**
- 电属性伤害减免 **+50%**
- 受到的电系伤害再按 **50%** 回补为治疗（下一帧生效，绿色数字）
- 风暴防护 +2（两件合计），风暴区的雷暴天气对你无效

**引雷术（击杀触发）：**
- 亲手击杀敌人时，以尸体为中心向 **6 米**内最近的 **3 个**敌人放出连锁闪电，各 **35 点电伤**
- 被闪电打死的敌人再触发下一跳，最多 **3 跳**，每跳伤害 ×0.75
- 首跳只认武器 / 手雷的直接击杀（持续伤害与套装自身的伤害不起链），首跳间隔 0.4 秒

**雷霆反震（受击触发）：**
- 被距离 **6 米以内**的攻击者命中时，有 **25%** 概率在自身位置释放**电击 AOE**：半径 **4 米** / **30 点电伤**
- 每 **3 秒**最多触发一次
- 不会伤到自己与友军（爆炸按阵营过滤），并对攻击者甩出一道电弧

## 与霜冠套装的区别

- 减伤与回补类型：雷霆是电，霜冠是冰
- 击杀技能：雷霆是连锁闪电（打伤害、能连跳），霜冠是霜爆（打控制、冻一片）
- 反击：雷霆 25% / 3 秒冷却 / 4 米 AOE，霜冠 30% / 5 秒冷却 / 冻结攻击者
- 天气：雷霆免疫风暴，霜冠抗寒冷

## 实战体验

- 引雷术在无间炼狱、末日丧尸这种成群小怪的场次最爽——一枪打死一个，周围三个跟着抽搐，连跳起来满屏电弧
- 反击 3 秒冷却比霜冠短，混战里触发频繁；30 点伤害不高，但叠加次数多时合计可观
- 电伤回补让你在风暴区和面对电系敌人时几乎不掉血
- 引雷术打出的击杀算你的击杀，照常计入图鉴、日报与战役目标

::: tip
雷神套装适合多敌密集的波次；霜冠套装更适合 1v1 控制场景。按需选择。
:::
