# 龙裔套装

## 这是啥？

龙裔遗族掉落的入门级自定义套装：**赤龙首**（头盔）+ **焰鳞甲**（护甲）。两件齐穿之后挨龙的火焰伤害，血会先掉，但下一帧能回来一大截。

## 单件属性

### 赤龙首（头盔）
- 护甲：7
- 耐久：200
- 物理承伤倍率：-10%
- 风暴抗性：+1
- 寒冷抗性：+1
- 枪械暴击伤害：+10%
- 火焰承伤倍率：-15%
- 电击承伤倍率：-15%
- 毒素易伤：+30%
- 视野角度：-20%
- 掉落来源：龙裔遗族（30% 掉率）

### 焰鳞甲（护甲）
- 护甲：7
- 耐久：200
- 物理承伤倍率：-20%
- 风暴抗性：+1
- 寒冷抗性：+1
- 火焰承伤倍率：-20%
- 电击承伤倍率：-20%
- 毒素易伤：+40%
- 掉落来源：龙裔遗族（60% 掉率）

## 两件齐穿——真正的套装效果

### 被动：火伤回补
- 挨火焰伤害照样先掉血，下一帧按火焰部分伤害的 **80% 补回生命值**——不是免伤，净亏大概 20%
- 燃烧（点燃）Debuff 本身不受影响，该烧还是烧，套装不解毒
- 两件齐穿时头部会亮起红色龙眼光效，纯装饰，不影响战斗

### 主动：龙裔冲刺
- 双击方向键触发
- 冲刺 3 米，冷却 1.5 秒
- 靠瞬间位移躲身位，冲刺途中没有无敌帧，照样会挨打

## 实战体验

- 穿着龙裔套装打龙裔遗族：它的燃烧弹会先咬你一口血，但大半能补回来，比裸装扛火伤轻松很多
- 冲刺是纯位移技能，能躲开 Boss 的范围技能，但别指望冲刺途中能硬吃一发正面攻击
- 作为龙王套装的**过渡装备**，值得优先收集

::: tip
龙裔套装是你的火系 Boss 克星，也是通往龙王套装的第一步。冲刺功能可在配置中关闭（enableDragonDash）。
:::
