# 冰霜长矛

## 这是啥？

一把**冰属性长矛**，攻击距离是所有新武器中最长的，每次命中 100% 施加原版「寒冷」状态。面板伤害稳健，暴击偏低，适合喜欢隔着距离边打边控场的玩家。

- **类型**：近战武器 / **品质**：5 / **元素**：冰
- **获取**：大冰冰 掉落 20%（原版地图同样生效） / 叮当的小店（好感 5 级，限量 1 件）
- **死亡掉落**：放在对应装备槽中时不会因死亡掉落；只放背包里不受此保护

## 面板数据

- 伤害：32 / 攻速：1.3 / 范围：**2.4 米**
- 暴击率：3% / 暴击伤害：1.2 倍 / 护甲穿透：3
- 格挡子弹：0.5 / 体力消耗：8/击 / 出伤时间：0.09 秒 / 出血概率：0%
- 持械移速：104% / 寒冷防护：**+1**

## 冰霜穿刺（被动）

- 每次近战命中附带**冰属性**，并 **100%** 挂上原版的「寒冷」状态（降低移动能力、射速与冰抗）
- 自身额外获得 **寒冷防护 +1**（雪地/冰冻环境下更扛）

## 看起来是什么样

刺击时矛尖拖出**冰蓝色残影**，命中的目标脚下会点一圈小霜环。霜环刻意做得比其他武器的特效小，因为它每次命中都会出现，太抢眼反而碍事。同一目标 0.35 秒内只点一次，高攻速下不会糊屏。

## 实战体验

- 2.4 米攻击范围，不用紧贴 Boss，能边打边保持距离
- 每击施加寒冷，配合中距离攻击范围更容易保持距离，但不会把目标冻在原地
- 暴击面板（3% / 1.2x）是所有新武器里最低的，不适合暴击流堆叠
- 无右键技能，操作简单，上手门槛低

::: tip
在丧尸模式中，寒冷减速对冲刺丧尸、骚扰丧尸特别好用，它们很难贴到你脸上。
:::
