# 宿命回响攻略

# 核心思路

这是一个**先读你，再考你**的模式。不要把上一局最顺手的打法当成固定答案：距离、弹药和枪械/近战偏好都会被记录。真正稳定的配装，应该至少准备两种输出距离、两种伤害方式和一套备用弹药。

# 入场前准备

- 主武器带一套，备用武器尽量准备不同的伤害方式
- 弹药不要只带一种口径，至少留出切换空间
- 带足治疗和基础消耗品；九波没有普通 BossRush 那种每波结束就能无条件重整的节奏
- 宿敌已经到 R2/R3 时，准备移速、爆发或远程安全输出方案
- 契约不是装饰：看到两个候选后，选一个你确实能围绕它安排路线的目标

# 第一幕：先建立画像（1-3 波）

# 第 1 波

- 这是署名或首个编排 Boss，优先熟悉地图和刷新位置
- 不要为了刷伤害数据在开局乱换弹；保持一套清楚、可复盘的打法
- 如果准备走距离契约，可以有意识地把终结距离控制在一个极端区间

# 第 2 波：距离学习

- 系统会读取第 1 波的可信终结距离
- 如果上一波贴脸，下一波就拉开；如果上一波一直远射，下一波就主动压近
- 只改变站位还不够，需要从新距离打出足够的有效伤害，才算破解

# 第 3 波：第一次宿敌与弹药点名

- 先看 HUD 是否公布了被点名弹药
- 被点名弹药不要继续贪用，换弹、换枪或直接切近战
- 这一波同时有宿敌压力，优先保证不在禁令中违规，再考虑 Last Stand

# 第二幕：开始分配资源（4-6 波）

- 第 4 波属性封锁会压低你上一波主要使用的一侧伤害效率
- 上一波枪械占比高，这一波就准备近战或另一套枪械；反过来也一样
- 第 5 波再次处理距离，别在同一种站位上连续赌两次
- 第 6 波是宿敌波并公布弹药点名；治疗、弹药和撤退路线都要提前留好

这一幕最容易因为贪 Resolve 过度消耗资源。契约进度很重要，但活着进入第三幕更重要。

# 第三幕：为第 9 波留答案（7-9 波）

- 第 7 波再次属性封锁，提前确认备用伤害方式还能正常输出
- 第 8 波是最后一次距离学习，决定你能否用熟悉以外的距离完成破解
- 第 9 波是弹药点名 + R3 宿敌，保留最可靠的弹药和爆发手段，不要把所有资源都花在第 8 波

# Last Stand 要不要抢？

Last Stand 只在多 Boss 波（第 2、5、8 波）触发，全局最多 3 次机会。

- **稳妥打法**：倒计时内直接收掉最后一只 Boss，能过波就行
- **契约打法**：确认自己能用可计分的枪械或近战完成末击，再去争 Resolve
- **危险打法**：为了多 1 点 Resolve 硬拖 12 秒，结果被宿敌反杀

如果 Last Stand 超时，Boss 会回血并获得移速、枪械/近战伤害强化。没有把握时，别把稳定通关换成一次贪心。

# Resolve 怎么规划？

Resolve 上限 11，奖励档位是：

- 0-2：6 件
- 3-5：7 件
- 6-8：8 件
- 9：9 件
- 10-11：10 件

从 6 到 8 是一个实际的奖励台阶；如果当前契约要求三轴各破解一次，优先保证轴目标，不必为了冲 10 点在每一波都冒险。

# 宿敌复战

- R1 宿敌先观察它的移动方式和技能节奏
- R2 开始要提前准备位移和安全距离
- R3 重点是爆发窗口和备用弹药，别把它当成普通 Boss
- 失败后新宿敌会成为下一局的目标，记住它的刷新幕次和自己上次的失误点

# 常见误区

- **只带一把枪** — 被属性封锁或弹药点名后没有第二答案
- **学习波乱扫弹** — 样本被污染，系统可能直接放弃弹药判断，契约也更难完成
- **把 Last Stand 当必做任务** — 它是额外得分窗口，不是每波通关条件
- **只看 Boss 数量不看轴目标** — 三 Boss 波未必最难，真正危险的是没有准备好反制方式
- **为了奖励把信物当成本** — 胜利会返还信物，失败才是本局的真实成本

::: tip
最舒服的循环通常是：第一波稳定输出、第二波主动换距离、第三波保守处理宿敌和弹药点名；熟悉这个节奏后，再逐步把 Last Stand 和契约目标加进路线。
:::
