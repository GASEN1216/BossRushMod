# 划地为营攻略

# 核心思路

沙盒混战，没有固定胜负条件。你可以：
- 帮自己阵营干掉其他阵营
- 坐山观虎斗，等他们打完你收割
- 选独狼，**一个人打全图**

# 阵营怎么选？

- **随机** — 随机分配，喜欢惊喜的选这个
- **拾荒者 / USEC / 实验室** — 标准阵营，Boss 池均衡，常规体验
- **BEAR** — Boss 属性 x2.5，友军也更强。**想要猛队友就选它**
- **狼群** — 优先生成狼群特色 Boss，想体验狼群特色的选
- **独狼** — 没有友军，5 个阵营都是你的敌人。**你确定？**

# 战术消耗品什么时候用？

- **挑衅烟雾弹** — 场上 Boss 少了，补充新目标
- **混沌引爆器** — 想看全图大混战时扔一个，场面壮观
- **猎王响哨** — 把附近 Boss 集中过来围歼
- **血狩烽火** — 全图 Boss 追你。**高风险高回报，勇者限定**

# 经济策略

- 分类商店使用本局贝壳，商品价格按原现金价每 2500 向上换算；出售物品仍拿账户现金
- 亲手击杀敌对 Boss 拿完整贝壳；否则，Boss 死亡时站在 8 米内拿一半。同阵营单位不给贝壳，也不掉敌对战利品箱
- 前几笔贝壳优先补主武器、弹药和保命装备。子弹购买后自动补满一组
- 分类抽奖价格取当前分类的中位价，时间越久高品质权重越高；缺明确目标时再抽，有核心装备需求就直接买

# 雇佣顺序

- 雇佣基础价看 Boss 最大生命，当前每多一只存活佣兵，下一只价格翻倍
- 便宜但能稳定跟随、输出的 Boss 往往是第一只佣兵的好选择
- 佣兵击杀算你的击杀，可以帮你叠玩家成长；但被雇佣后，它死亡就不再给贝壳
- 雇佣没有硬上限，真正限制你的是贝壳收入和越来越高的报价

# 成长机制——越打越强

- **Boss 成长**：每只 Boss 独立结算，同阵营每有单位阵亡就叠层。每层 +5% 生命/+5% 枪伤/+5% 近战伤。新刷的 Boss 不继承旧层数
- **玩家成长**：亲手给敌对 Boss 补最后一刀就叠 1 层。每层 +0.1% 生命/枪伤/近战伤，持续累积
- 叠层时头上显示：`生命/伤害+0.1%，总加成xx%`

# 独狼攻略

- 没友军，5 个阵营全是敌人
- 开局送额外补给物资
- **核心策略：让不同阵营 Boss 互相打**，你坐收渔利
- 血狩烽火可以把全图 Boss 引到一起互相混战——**让他们自相残杀**
- 最难的模式变体，装备成型后再来
